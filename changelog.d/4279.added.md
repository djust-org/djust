Added `DJUST_UNSUPPLIED_NAMES` (`"debug"` default, `"warn"`, `"error"`): `"error"` raises `UnsuppliedTemplateNameError` on every render of an explicit view whose template reads a name the view holds but nothing supplies, so a test run (where `DEBUG` is off and the `djust.exposure` notice never fires) fails instead of rendering blank; `"warn"` logs whatever `DEBUG` is. Names a context processor supplies (`user`, `messages`, ...) are not reported. The value is case-insensitive; an invalid one is a new `djust.C043` error at `manage.py check` and, at render time, is logged once and behaves as `"debug"`. `UnsuppliedTemplateNameError` is importable from `djust.testing`.
