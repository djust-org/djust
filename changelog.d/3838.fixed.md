- **A dict `lazy=` on `{% live_render %}` works under the native (Rust) engine (#3838).** `{% live_render "app.views.Child" lazy=cfg %}` with `cfg = {"placeholder": ..., "trigger": "visible"}` rendered under the Django engine but raised `TemplateSyntaxError: lazy= accepts True, 'visible', or a dict - got '{"placeholder":...}'` under the native one, because the engine hands a handler a structured operand as a JSON string. `LiveRenderTagHandler` now declares `TYPED_ARGS` (the channel `json_viewer` uses, #3756) and reads `lazy` as the value the engine resolved, not the string decoded back: a string cannot carry `SafeString`-ness, and the #3819 placeholder contract depends on it. A `mark_safe` placeholder is markup and a plain `str` is text on both engines, byte for byte. The same read means a string variable holding the text `'visible'` (quotes inside) is refused as Django refuses it; the native handler used to strip the quotes and accept it. Only `lazy` is read this way; the other keyword operands are the child's `mount()` kwargs and cross as they always did. `TYPED_ARGS_KEY` now lives in `djust.template_tags` (re-exported by `djust.components.rust_handlers`). `tests/unit/test_native_live_render_lazy_dict_3838.py`, gate-off verified (6 mutations).
