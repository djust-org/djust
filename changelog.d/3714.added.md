- **`scripts/gate_off.py`: one shared gate-off harness (#3714).** State the mutations as data (file, text to find, replacement, label, and the test command that must catch it) in a `.json` or `.toml` file and run `python scripts/gate_off.py <file>` to get a `CAUGHT` / `SURVIVED` / `INVALID` table. It implements the rules CLAUDE.md already states (the issue records five v1.3.0-15 PRs each re-learning them in a throwaway harness): a mutation text that is not found (or found the wrong number of times), a replacement that changes nothing, a `.py` target that no longer compiles, a smoke command that fails on the mutant, tests that fail to collect (pytest's `1 error`, not `1 failed`) and a run in which no test passed are all `INVALID`, never a number; test-time errors are counted with failures; each run has a deadline and an RSS ceiling over its whole process group and a runaway is reported as `CAUGHT` (`HUNG` / `RUNAWAY-MEMORY`) with the measurement; the file is restored from saved bytes in a `finally` (also on SIGINT, SIGTERM, SIGHUP and `atexit`), written to a new inode with a fresh mtime, and verified byte-identical by SHA-256 (`RestoreError`, exit 3, otherwise); `__pycache__` for each touched file is cleared before and after. A red unmutated baseline stops the run. It cannot judge an equivalent mutation or two shadowing mechanisms; a `SURVIVED` row prints that question. 38 regression cases in `tests/unit/test_gate_off_3714.py` run it against a real fixture package (caught, survived, no-op, import-breaking, setup-error, endless-loop, runaway-allocation, smoke-failing mutations; a crash and a real SIGINT / SIGTERM mid-run both leave the file restored). The harness is gate-off'd with itself: `scripts/gate-off-selfcheck.json` drops each rule in turn and every drop turns a test red. CLAUDE.md's three gate-off paragraphs now point at the script.
