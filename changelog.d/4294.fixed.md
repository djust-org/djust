- **`template_paths()` and `serialize_for_template()` read the cached template source.** With `DEBUG` off they used to resolve the `{% extends %}` chain and re-inline every `{% include %}` on each call, so a `get_context_data()` that calls `serialize_for_template()` per key paid one full template resolution per key on every render. They now read the per-template source cache every internal caller uses. With `DEBUG` on, the unsupplied-name notice (#4279) reads the template once per view class until the template cache is cleared (hot reload, `override_settings`), not twice on every render; `DJUST_UNSUPPLIED_NAMES = "error"` still reads it once per render (#4294).
