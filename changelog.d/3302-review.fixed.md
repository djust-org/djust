- Ignore literal root markup inside textarea RCDATA when selecting, stamping, or balancing a LiveView root in Python and the native text scanner. This corrects the documented `lookalike_in_textarea` corpus divergence to browser semantics and lets body roots mount over WebSocket/SSE. Retained body scripts are not rerun or marked executed based on DOM presence; DEBUG reports their execution status as unknown, since parsed scripts may have run while innerHTML-created scripts remain inert.
