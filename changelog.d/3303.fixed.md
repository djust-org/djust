- The HTTP event fallback (`LiveView.post()`) now honours a navigation the handler queued. A `live_redirect` is returned as a `_navigation` list of WebSocket-shaped `navigation` frames and nothing is rendered or saved, so a handler that calls `logout()` then `live_redirect()` no longer renders against the anonymous request (a 500 before); a `live_patch` renders as before and carries its frame. The client hands each frame to `djust.navigation.handleNavigation`, which does a full-page navigation when no socket is connected (#3303).
