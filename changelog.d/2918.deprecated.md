- **Dict-style access to `block` in a Python-bridged tag is deprecated (#2918).** `context["block"]["super"]`, `block.get("super")`, `block.values()`, `block.items()` and `dict(block)` (the shape of the `dict` the tag received before `{{ block.super }}` became lazy) still work, but each read now emits the standard djust `DeprecationWarning`, pointing at the tag's own line: deprecated since 1.3, removed no earlier than 2.0.0, use `context["block"].super()` instead. Each read still renders the parent once with no memoization, and the parent's own exception class reaches the tag's `except` unchanged. Django's own resolver (`Variable("block.super")`, `{% blocktranslate with s=block.super %}`) (and djust's own Rust resolver) is recognised and takes the `super()` method as in Django, with no warning, even when `Variable._resolve_lookup` is wrapped by a profiler or monkeypatch. Covered by `python/tests/test_block_super_bridge_lazy_2918.py`.
