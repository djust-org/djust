- **A repeated form-field name is now a list for `dj-submit` handlers, under the legacy policy as well (#3959).** A handler that read a repeated name as one string, for example the hidden-input-plus-checkbox idiom (`<input type="hidden" name="x" value="0">` then `<input type="checkbox" name="x" value="1">`, which used to see the last value), now receives `["0", "1"]`: read the last element, or give the inputs different names. A legacy handler that declares such a name as `str` gets a type error rather than a silently dropped value. See "Fields with several values" in `docs/website/guides/forms.md`.
