- A component built without an explicit `component_id` during a render of a view (for example a navbar built in `get_context_data`) now gets the same default id on every render, derived from the view's class, the component's class and its position in that render, so a page that uses one can get HTTP fallback patches instead of the whole page. Two components of one class in one render keep different ids. A component built in `mount()` or an event handler keeps its random id. (#4114)
