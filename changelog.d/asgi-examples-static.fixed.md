- **The framework's own `asgi.py` examples now serve static files.** `djust.schema.BEST_PRACTICES["setup"]["asgi"]` (what the MCP server and `djust ai` hand to agents) and the `DjustMiddlewareStack` docstring example both showed a bare `"http": get_asgi_application()`, the exact shape the same module lists as common mistake 5 ("static files returning 404 with ASGI servers"). Both now wrap the HTTP handler in `ASGIStaticFilesHandler` and call `get_asgi_application()` before importing djust, matching the `djust new` scaffold and the README (#3653).
