- `djust.PersistentLiveView` is a `LiveView` base class that sets `enable_state_snapshot = True`, so a project can opt a group of legacy-exposure views in to the session-backed state restore by inheriting from it. A subclass can still set the flag back to `False`; views with `exposure_policy = "explicit"` ignore the flag and keep persisting only their `state(..., persist=...)` fields; `djust.C304` still checks every subclass. The default for `LiveView` is unchanged.
