- **Per-model serialization settings are honoured for lazily wrapped model instances.** `djust_exclude_fields`, `djust_serializable_fields`, `djust_serialize_sensitive_fields`, `to_dict()` and the column-type rule are read from the model class a wrapper reports through `__class__`, on the native engine (a bare read, a dotted filter, a filtered rebinding), the `{% load %}` bridge, the eager serializer, the JIT attribute gate (which decides by name) and a `ModelForm` over a wrapped instance. A wrapper that cannot be evaluated raises. A model that declares none of these settings renders as before. Regression cases in `python/tests/test_per_model_rules_lazy_wrapped_model.py`.
