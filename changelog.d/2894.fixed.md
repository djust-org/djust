- **A raw block tag that names its own closing tag now bridges to the Rust engine.** The ADR-030 wrapper probe looked for `end<name>` rather than the end tag the tag's closure names, so a wrapper such as `end_theme_card_block` was refused as having more than one body segment (`LibraryBlockTagHandler` already used the right name at render time). The probe also now gives a wrapper that reads `context["request"]` the probe request instead of an empty string.
