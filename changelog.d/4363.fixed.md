- **Page loads and socket mounts no longer re-parse the template tree on every request
  (#4363).** 1.3.5's dj-model gate remembered its answer per view instance, and every
  GET and mount builds a new view, so each one re-parsed the page and every literal
  `{% include %}` site, running the `{% load %}` hook for each. With render caches on
  (`DEBUG` off) the gate now shares the walk through the dj-model split cache, and an
  already-bridged library's `{% load %}` answers from the registry generation instead
  of probing every tag.
