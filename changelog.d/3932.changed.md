- **A `Component` drawn through its `template` now escapes a marked-safe value in an ordinary text slot, as its Rust instance does (#3932).** `Alert(text=mark_safe("<b>x</b>"))` printed `&lt;b&gt;x&lt;/b&gt;` from the Rust instance and `<b>x</b>` from the template path (a lazy string, or a class with no crate twin such as `Checkbox`), so the same value printed as markup or as text depending on which path the constructor picked. The template path now escapes a `{{ }}` in ordinary text whatever the value is marked as (`{{ v|safe }}` too), except the names a class lists in the new `Component.markup_slots`: `Modal` (`body`, `footer`), `Tooltip` (`content`) and `Offcanvas` (`body`), which already escape a plain string in their constructors and document `mark_safe` markup. A `{% %}` tag in ordinary text is not a slot and is left as it is. To print markup from your own `Component` subclass, add the parameter to `markup_slots` or use a `LiveComponent`; `LiveComponent` and `BoundComponent` inline templates are unchanged and keep markup in a text slot. Tests in `python/djust/tests/test_component_hybrid_rawtext_and_live_templates_3913_3914.py` and `python/djust/tests/test_ui_simple_components_escaping.py`.
