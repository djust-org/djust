- **URLs are normalised the way a browser reads them before the same-site test.** The data table's row navigation (`data-table-row-click.js`), the map picker's tile and asset URL (`map_picker._plain_url`, `map-picker.js`), `validate_mount_url` and `same_origin_target` now apply the browser's own URL normalisation before deciding whether a URL stays on the site, through one definition (`djust.security.urls.url_as_parsed` and `url_is_protocol_relative`, mirrored in the two static scripts). `same_origin_target` also answers `"/"` for a URL its parser refuses, where it raised. `url_allowed` / `url_attr` are unchanged: they are a scheme allowlist, and their docstring now says so. Absolute `http(s)` row URLs are still followed. A differential over about 120,000 generated URLs checks the helper, the unchanged JavaScript guard and the Python decisions against the browser's URL parser and Django's `url_has_allowed_host_and_scheme`.
