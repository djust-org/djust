- **The Python render and the Rust VDOM now agree on which element is the LiveView root (#3031).** One rule on all three locators: an embedded `{% live_render %}` child's wrapper and everything in it belong to the child and are never the parent's root; of the rest, the first `dj-root` wins, else the first `dj-view`. Python extracts a view's root from its template and hands Rust only that element, so a page that has a root renders and patches exactly as before. Three things change. A page with no root of its own that embeds a child no longer gets a VDOM rooted at the child's wrapper; it falls back to the first element in `<body>`, as any rootless page does (the page is not live either way). Python now recognises an embedded wrapper written with upper-case `DATA-DJUST-EMBEDDED`. And raw input given straight to the Rust VDOM or its text scanner, such as `<nav dj-view>` before `<main dj-root>`, now picks `<main>`, as Python does.
