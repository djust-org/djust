- **The Python render and the Rust VDOM now pick the LiveView root with one rule (#3031).** The first `dj-root` in document order wins, else the first `dj-view`, and an embedded `{% live_render %}` child's wrapper and everything in it are never the parent's root. The VDOM and its text-fast-path scanner used to take the first element carrying either attribute, children included, so `<nav dj-view>` before `<main dj-root>` rooted the VDOM at `<nav>` (Python picked `<main>`), and a page with no root of its own that embedded a child rooted it at the child's wrapper. Python also missed an embedded wrapper written with upper-case attribute names. Pages whose root Python already picked, which is the one the client mounts, behave as before; the one-time change is for pages that declared `dj-view` on a different element than `dj-root` (`djust.T005` already warns), and for pages with no root of their own that embed a child.
