- **`dj-root` wins over `dj-view` on both sides (#3031).** On a page with a
  `dj-view` element before a separate `dj-root` element
  (`<nav dj-view=…>…</nav><main dj-root>`), Python built the page from `<main>`
  while the Rust VDOM rooted at `<nav>`, so patches were computed against the
  wrong element. The VDOM and the Rust text scanner now use Python's rule: the
  first `dj-root` element, else the first `dj-view` element. `T005` still
  warns about this layout.
