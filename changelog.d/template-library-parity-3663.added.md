- **A parity ratchet for djust's own template libraries (#3663, #3669).** `make template-library-parity` renders every `djust_components` and `theme_tags` tag that has a native handler through Django's engine and through `DjustTemplateBackend`, and compares a per-tag table with the checked-in `scripts/template-library-parity-baseline.csv`: the class (`IDENTICAL`, `DIFFERENT-escape-policy-only`, `DIFFERENT`, `UNEXERCISED`), how many variants differ and in which aspects, which variants one engine rejects, and how much of the tag was exercised. Discovery follows each handler into the `render_*` helper that reads its arguments, every string parameter is called alone with a `mark_safe` and a hostile value, and a child tag is rendered inside an open parent and compared on what it added. The ratchet is exact in both directions: a tag that gets worse fails, and so does one that gets better (with the command that regenerates the baseline). The harness runs in its own process with fixed uuids and clock; `python/tests/test_template_library_parity_3663.py` carries its gate-offs and `scripts/template-library-parity-gateoff.py` mutates the ratchet and the tags to show each turns the test red. New `pr_tier` test marker (`tests/slow_tier.py`): a test carrying it stays in the PR fast tier however long `.test_durations` records it.
