- **A parity ratchet for djust's own template libraries (#3663, #3669).** `make template-library-parity` renders every `djust_components` and `theme_tags` tag that has a native handler through Django's engine and through `DjustTemplateBackend`, classifies each tag (`IDENTICAL`, `DIFFERENT-escape-policy-only`, `DIFFERENT`, ...) with the structural aspects that differ and any variant one engine rejects, and compares the table with the checked-in `scripts/template-library-parity-baseline.csv`. The ratchet is exact in both directions: a tag that gets worse fails, and so does one that gets better (with the command to regenerate the baseline), so the gap can only shrink. The harness runs in its own process with fixed uuids and clock, and `python/tests/test_template_library_parity_3663.py` carries its gate-offs (Django against itself must be all `IDENTICAL`; a difference planted in the Python tag must be caught). `make template-library-parity-baseline` regenerates the baseline.
