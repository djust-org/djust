- **`dj-prefetch="false"` now opts a link out of the service-worker hover prefetch too (#3327).** The attribute used to skip only the intent prefetch (`dj-prefetch`); the older service-worker path in `22-prefetch.js`, which warms any same-origin link under an active service worker, checked only `data-no-prefetch`, so `<a dj-prefetch="false" href="/logout/">` was still prefetched on hover. Both layers now honour it, and `data-no-prefetch` keeps opting out of the service-worker path. Regression case in `tests/js/prefetch.test.js`.
