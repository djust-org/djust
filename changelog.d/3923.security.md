- **A Component's hybrid template judges a URL whose character reference is completed by the slot (#3923).** `href="&#10{{ s }}"` with `6;avascript:...`, or `href="javascript&{{ s }}"` with `colon;...`, printed a value the browser reads as `javascript:`: each literal was decoded before the slot's text was joined to it, and a literal ending in `&` counted as fixing the value. The value is now decoded as it is printed (the literal text and the slot's escaped text together) before the scheme check, a literal ending in an unfinished character reference no longer fixes the value, and a dotted or filtered slot after one is listed in the warning as escaped but not judged. Regression tests in `python/djust/tests/test_hybrid_attrs_charref_join_3923.py`.
