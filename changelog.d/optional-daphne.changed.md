- **Packaging: daphne is now an optional extra, `djust[daphne]`** — djust's base dependency is plain `channels>=4.0.0,<5` instead of `channels[daphne]`, so a bare `pip install djust` no longer installs daphne or, through `daphne -> twisted[tls]`, Twisted (or autobahn, pyOpenSSL and service-identity). Apps served by uvicorn or hypercorn, which never import either, stop carrying Twisted's advisories in their dependency audits; eight of them, most recently GHSA-vpp8-g58w-m8mp (HTTP/2 rapid reset), had to be ignored downstream. **Migration:** an app that serves with daphne, or lists `"daphne"` in `INSTALLED_APPS` for its `runserver` override, must now install `djust[daphne]` (or depend on `daphne` directly); without it, Django fails at startup with `ModuleNotFoundError: No module named 'daphne'`. `djust new` projects already use uvicorn and plain `channels` and need no change. `djust[all]` and the `dev` extra include daphne. `djust_doctor`'s no-ASGI-server hint now names `pip install 'djust[daphne]'`, and the installation, system-check and error-code docs say how to get daphne. `tests/test_base_dependencies_no_daphne.py` fails if daphne or Twisted becomes a base dependency again, directly in `pyproject.toml`, transitively through `uv.lock`, or in the installed package metadata.
