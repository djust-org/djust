- New system check `djust.T024` warns when a template a LiveView or LiveComponent renders reads `is_staff`, `is_superuser` or `password` through a `user` variable (`{% if request.user.is_staff %}`). The serializer never ships those fields, so the expression was silently always false. The BEST_PRACTICES guide documents the derived-boolean pattern (`self.can_manage = request.user.is_staff`, or a context processor) (#3282).
