- **A live mount no longer renders the whole page shell when nothing in it can mount a child view.** An explicit-exposure view whose page shell comes from `template_name` rendered the full page on every WebSocket mount, only to register child views outside `dj-root`, and discarded the HTML. The mount now skips that render when the template source (its `{% extends %}` chain with static includes inlined) names no `live_render`, has no unresolved `{% include %}` and loads no tag library beyond Django's `static`, `i18n`, `l10n`, `tz`, `cache`, `humanize` and djust's `live_tags`. The answer is cached per template while render caches are on (#4295).
