- **The `reauth` turn-middleware built-in and the legacy arm of every turn are removed (#4201).** `reauth` re-checked only legacy-exposure views, under `LIVEVIEW_CONFIG["reauth_on_event"]`; every turn of an explicit view is authorized against the session the server stores, so the chain is now `error_boundary`, then `LIVEVIEW_MIDDLEWARE`. Mount, reconnect, event, URL change, push, tick, `db_notify`, presence, background start and result, recovery render and deferred-event turns have one path on WebSocket, SSE, the HTTP fallback and the HTTP API.
