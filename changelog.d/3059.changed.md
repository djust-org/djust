- **BREAKING: Python 3.11 is now the minimum supported version; Python 3.10 is dropped (#3059).** `requires-python` is `>=3.11` and the 3.10 classifier is gone, so `pip install djust` on 3.10 now resolves to the 1.2 line, or fails if you pin `djust>=1.3`. **Upgrade path:** move the environment to Python 3.11 or newer, or stay on `djust>=1.2,<1.3`, which keeps receiving fixes. The reason is a security one: every autobahn release from 25.9, including the patched 26.7.1 (Dependabot #157, `permessage-deflate` bypassing `maxMessagePayloadSize` after inflation), requires Python 3.11 or newer, so the 3.10 lock entry (autobahn 24.4.2, reached through `djust[daphne]` → `channels[daphne]` → `daphne`) could never be patched. `uv.lock` now carries a single autobahn entry at 26.7.1, and the reviewed `CVE-2026-77528` exception is removed from `.github/security/pip-audit-ignore.txt`. The release wheel matrices (`release.yml`, `publish.yml`) no longer build cp310 wheels, ruff's `target-version` and mypy's `python_version` move to 3.11, `djust_doctor` fails the `python_version` check below 3.11, and the scaffolders (`djust init` setup, `djust_theme` package template) write `>=3.11`. The 3.10-only `tomli` fallbacks (theming manifest reader, `djust init`'s dependency reader, `scripts/check-test-coverage.py`) now import the standard library's `tomllib` directly. The ABI and wheel strategy (#3255) is a separate decision and is unchanged.
