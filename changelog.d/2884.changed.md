- **`djust init` reports the documented `TEMPLATES` shape, and `djust init --templates` adds it (#2884).** `djust init` never edits `TEMPLATES`: it prints an informational step and the entry that puts `DjustTemplateBackend` first (now with `"NAME": "djust"`, matching the installation guide). With `--templates` it appends a marked block to a `TEMPLATES` it can read with certainty: the djust entry mirrors the first `DjangoTemplates` entry's `DIRS` and supported `OPTIONS`, and the project's own entries stay after it unchanged. A `TEMPLATES` that already lists the djust backend is left alone, and one `init` cannot read is ATTENTION only when `--templates` was passed. Removing the block is the undo: a rerun without the flag never adds it back. The installation guide now lists what djust's engine renders differently from Django's. 30 regression cases in `python/djust/tests/test_djust_init_templates_2884.py`.
