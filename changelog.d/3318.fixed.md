- `{% theme_nav_item %}` keeps its active state across `dj-navigate` when the nav sits outside `dj-root`. The tag stamps `data-dj-nav="<url>"` on a link whose state it auto-detected, and `components.js` recomputes the `active` class and `aria-current="page"` on `djust:navigate-end` and back/forward with the same rule the server uses (exact for `/`, path prefix otherwise); an explicit `active=` is left alone. `dj-navigate`'s exact-match `aria-current` sync now skips `data-dj-nav` links so the two cannot disagree (#3318).
