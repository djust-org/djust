- `{% theme_nav_item %}` keeps its active state across client-side navigation when the nav sits outside `dj-root`. The tag stamps `data-dj-nav="<url>"` on a link whose state it auto-detected; the client now dispatches `djust:path-changed` on `document` whenever the rendered pathname moves (live_redirect, live_patch to a new path, auto-navigate click), and `components.js` recomputes the `active` class and `aria-current="page"` from it and from back/forward. The rule is shared with the server and is now segment-aware (`/docs` is not active on `/docs-old/`), tolerant of a missing trailing slash, and percent-decoding on both sides; an explicit `active=` is left alone, and `theme_nav_item` no longer raises on `url=None`. `dj-navigate`'s exact-match `aria-current` sync skips `data-dj-nav` links while `components.js` is loaded (#3318).
