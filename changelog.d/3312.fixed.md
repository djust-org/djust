- **`djust_ai_context` encoding and partial files, `djust init` hash-locked requirements, hot-reload banner (#3312).**
  `djust_ai_context` now writes UTF-8 whatever the locale (under `LC_ALL=C PYTHONUTF8=0` the first run died on the em
  dash after creating the file, leaving a 0-byte `CLAUDE.md` the rerun then refused), removes a file whose write failed,
  and with `--force` writes beside the target and renames over it so a failure keeps the original. `djust init` no longer
  edits a `requirements.txt` that carries `--hash=` (in it or any file it includes): rewriting a line or appending one
  breaks `--require-hashes`, so it reports the requirements to add and recompile with hashes. The `[HotReload]` banner is
  written to stderr exactly once and never routed through logging, so it no longer vanishes under a non-console handler
  or a WARNING-level console handler. 15 regression cases in
  `python/djust/tests/test_djust_init_hash_locked_3312.py`,
  `python/djust/tests/test_ai_context_encoding_3312.py`.
