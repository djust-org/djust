- **A `dj-view` or `dj-root` on `<html>` or `<head>` is ignored, and the page stays a plain HTTP page (#3302).** It is unsupported (the VDOM starts at `<body>`), and before it mounted a view that replaced the document element's content: the body shrank to its first element and the client threw a TypeError. The server render is unchanged; the client now treats `<html>` and `<head>` as never a container (no mount over WebSocket or SSE, nothing stamped), and logs one console warning that names the fix. `djust.T025` keeps flagging them, and its message now says the attribute is unsupported and ignored and to put it on `<body>` or a `<div>`; the runtime warning says the same. A browser still running an older cached client script would mount such a page as before.
