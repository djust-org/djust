- **Marked-safe values are escaped in the attributes of the admin, allauth / djust_auth, bug-capture replay and gallery templates (#4157).** Django's autoescape leaves a value marked safe as it is, so a value marked safe for text could close an attribute of these pages and add another. Every attribute slot of the `djust_admin`, `allauth/elements`, `djust_auth`, `templates/djust/bug_capture/replay.html`, `djust_components/gallery` and `djust_theming/gallery` templates now uses `|force_escape`, and a URL attribute (`href`, `action`, `src`, `formaction`) goes through the new `djust_url_attr` filter (`{% load djust_attrs %}`), which escapes once and turns a `javascript:` / `vbscript:` / `data:` URL into `#` (the `data_url_attr` rule). Its filters bridge to the Rust engine on `{% load %}`, so a child template that extends another can use it. The #4009 sweep now covers these templates twice: a static pass over every `{{ }}` in a start tag, and a render of each page with every value the marked-safe payload (Django, and the Rust engine for the LiveView admin pages); both find nothing. Regression tests in `python/tests/test_marked_safe_attribute_sweep_4009.py` (`TestEveryPageTemplate`).
