`djust.T027` no longer skips a view silently because its template uses `{% extends %}` or because its `get_context_data()` returns a local (`ctx = super().get_context_data(**kwargs); ctx["x"] = ...; return ctx`, including `ctx.update(...)` and `ctx.setdefault(...)`). A `template_name` view is read through its `{% extends %}` chain and `{% include %}` partials, so a name read only in a base template or an include is reported (without a line number); names a mixin's provider contract renders (such as `TenantMixin`'s `tenant`) count as supplied, as does every name a configured `TEMPLATES` context processor supplies (`user`, `messages`, a project processor's keys). The Info message names up to five skipped views. What the check still cannot follow (an override that passes the context to a helper, an inline `template` with `{% extends %}`) is counted in one `djust.T027` Info message. Expect new T027 warnings on projects whose views extend a base template: they are real names that render empty. (#4278)
