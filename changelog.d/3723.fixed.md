- **`_blank_template_comments` is linear in the number of `{% comment %}` openers.** It searched for the end of each opener's line with `content.find("\n", position)`, which runs to the end of a template that has no newline once per opener: 4x the openers cost 14x as much (0.02 s to 0.30 s for 10,000 to 40,000 `{% comment %}`). The next newline is now remembered while the scan moves forward past it, and 4x the openers costs 4.1x. The output is unchanged: a differential test (`python/djust/tests/test_blank_template_comments_differential_3723.py`) compares the new function with the old one, kept verbatim as the oracle, over 47 hand-written templates and 4,000 seeded random ones, and the growth test that was `xfail(strict=True)` in `test_template_checks_skip_comments_3283.py` is now an ordinary test.
