- New opt-in `LIVEVIEW_CONFIG["state_models_as_handles"]` (default `False`), the render-time handle overlay of the ADR-027 addendum. Behavior change (flag on):
  - a custom filter or tag handed a state model receives the floor proxy, as on `DjustTemplateBackend`: attribute access works (`value.pk`, `value.get_full_name()`, a relation walk) and dict-style access (`value["name"]`, `.get`, `.items`, `isinstance(value, dict)`) stops working;
  - a Django-library tag that prints its operand writes the model's text on a LiveView, as on the other entries;
  - a native tag's argument (`data_table`, `table_cell`) is still the floored dict text.
  The floor holds as before: `password`, `DJUST_SENSITIVE_FIELDS`, `djust_exclude_fields` and `_`-prefixed names stay unreadable, and a key whose floor cannot be built renders from its dict. The ADR's actor-entry item is moot: `use_actors` was removed in 2.0. (#3949)
