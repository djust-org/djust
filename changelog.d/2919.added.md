- A reused sticky `{% live_render ... sticky=True %}` child can now take changed tag kwargs through a new `_on_sticky_update(self, changed)` hook (#2919). On the parent render that sees different values, djust calls it on the live child, before the child renders, with only the kwargs that are new or differ, mapped to their new values. The child is not remounted and its state is not reset. A child without the override behaves as before (new values ignored, one warning, which now names the hook). The name is private so no client event can reach it. A sticky preserved across `live_redirect` is not re-rendered and does not run the hook; `exposure_policy = "explicit"` children are remounted when inputs change. See the sticky LiveViews guide.
