- **`static_render = True`: a view that renders once keeps no diff baseline (#3626).** For a page that is rendered on the GET and the socket's mount and then not patched (a report, a diagram, a document), djust kept the rendered tree and a copy of every context value in the live view and in every stored snapshot, for a diff that never came. A view that sets the attribute drops both after each render (new `RustLiveView.release_baseline()`, which, unlike `reset()`, keeps the version counter, plus `retain_state_keys([])`), so the state backend stores only the template and the version. Measured on a page rendering a cached ~200 KB diagram of 2,000 nodes: 474,054 bytes stored after the GET (context 204,004, tree 269,862) became 196, and the `Large LiveView state` warning, which measures the stored bytes, no longer fires. Every later render is full and correct instead of a patch: an event that changes state answers `html_update` over the socket (`html` on the HTTP fallback, with consecutive versions, with `view_state_in_session` on or off), an event that changes nothing still answers `noop`, work started at mount (`start_async`) answers the whole page once it finishes, and navigating away and back, a reconnect and a mount after the GET render the page from the view's state. Such a full frame reports the reason `static_render` and logs no DJE-053 warning. An embedded or sticky child keeps its own baseline (a child with handlers inside a static page, and a static child inside a normal page, both update as before), and a native (LVN) renderer is never released. Opt-in, default off: a normal view is unchanged. The warning's advice names the attribute, and the Best Practices guide's "Large LiveView state" section documents the trade (a full render and a full-page frame per later render, against memory per open page and per stored snapshot) and when not to use it (pages whose own handlers update them often, `temporary_assigns`, streams). Stream rows in the snapshot of a view that does patch remain #3632. 15 regression cases in `python/djust/tests/test_static_render_3626.py`.
