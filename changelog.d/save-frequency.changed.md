- **Saved view state carries a holder epoch; states saved by an earlier 2.0 build are dropped once.** The automatic-state envelope (version 9) and a state store's session index entry gain an `epoch` field, so a view's saved state from before the upgrade is not restored: the first reconnect or fallback request after it starts from `mount()`, as for an expired state. A sealed state takes about 12 bytes more in the session.
