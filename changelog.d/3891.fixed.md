- **`params_form_fallback = "fields"` now hands `handle_params()` the value the valid path would for a kept field the URL left out or empty (#3891).** On a valid URL the form's `clean()` runs first and a field the URL left out or empty then takes its `initial` value, so `clean()`'s write to that field is overwritten. The `"fields"` fallback filled that `initial` *before* its extra `clean()` re-check and then adopted `clean()`'s output, so `clean()`'s write to such a field survived: a `clean()` that copies a request value into another field handed a value that failed validation to `handle_params()` through a field the URL never named, where a valid URL would have handed that field's `initial`. The fill is now applied to the re-check's output, with the same helper the valid path uses, and the re-check is given the raw cleaned values, as `clean()` sees them on a valid URL. A field the URL supplied still keeps `clean()`'s output on both paths, a field with no `initial` is not filled on either, a failed field is still its `initial` value, and `"initial"` mode is unchanged. Guide: Navigation, "Keeping what validated".
