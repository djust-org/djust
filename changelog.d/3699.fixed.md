- **`TtydTerminalView` no longer 500s on a bad `?rows=` / `?cols=`, and no longer accepts an unbounded size** — a value that is not an integer (`?rows=x`, `?cols=`) now falls back to the view's class default instead of raising `ValueError`, and an integer is clamped to 1..500 rows / 1..1000 columns (a digit string too long for `int()` to parse is a huge number and clamps to the cap, whatever `PYTHONINTMAXSTRDIGITS` is set to) before it reaches the CSS `calc()` min-height and xterm, so a link cannot make the viewer's own tab allocate a huge terminal. `?theme=` was not affected (#3699).
