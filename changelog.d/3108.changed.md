- **MarkdownEditor: the selection (bubble) menu is on by default in Visual
  mode, for existing editors too (#3108).** Selecting text in a Visual-mode
  editor now shows a small formatting menu next to the selection. It never
  replaces the browser's context menu. To keep the previous behaviour, pass
  `bubble_menu=False` to `MarkdownEditor(...)` or the `{% markdown_editor %}`
  tag, `bubble_menu=False` to the `markdown_controls.html` include, or put
  `data-bubble-menu="false"` on a hand-written host. An explicit `data-actions`
  list also filters the menu, and a menu it leaves empty is not shown.
