- `manage.py check` has a new warning, `djust.T025`, for `dj-view` / `dj-root` on `<html>`, `<head>` or `<body>`. The HTTP render of such a page is complete, but the WebSocket mount keeps only the first element inside `<body>`, so the live page silently lost content. The check skips `{% verbatim %}` regions, HTML comments and `<script>` bodies, and one match can be silenced with `{# noqa: T025 -- <reason> #}`. `djust.T002` no longer says a root on those elements "still connects": it stays silent for them and limits its reassurance to a root inside `<body>`. The mount-time root detection itself is unchanged (#3302).
