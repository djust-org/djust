- **An item value that is marked safe is escaped in every attribute a template tag writes it to (#3904, follow-up to #3898).** Behaviour change: an entry of a list parameter, or a value read out of an item dict, that is marked safe (`mark_safe`, a lazy one, a subclass, a `str` with `__html__`, or an object whose text form is marked safe) used to be written as it is into an attribute (`value=`, `data-*`, `id=`, `class=`, `aria-label=`, `fill=`, ...) by 37 tag parameters: `audit_log` (`entries`, `columns`), `autocomplete`, `collab_selection`, `combobox` (`options`, `selected`), `cursors`, `dashboard_grid`, `data_grid` (`columns`, `rows`), `dependent_select`, `dj_select`, `export_dialog` (`columns`, `formats`), `fab`, `file_tree`, `gantt_chart`, `kanban_board` (a column and the cards inside it), `line_chart`, `masonry_grid`, `meter`, `model_selector`, `multi_select`, `notification_center`, `reactions`, `scroll_spy`, `sortable_list`, `split_button`, `tag_input` (`tags`, `suggestions`), `toast_container`, `toggle_group`, `tour`, `tree_view`, `wizard`, and `theme_radio` / `theme_select` of `djust_theming`. It is now escaped there exactly as a plain string is (`attr_text` in the Python tags, `|force_escape` in the three templates); text slots keep their markup. A scalar tag argument is unchanged. `test_marked_safe_attribute_sweep_3898.py` now drives each of the 37 parameters (a cell each: the attributes the item reaches are pinned, and every kind of marked-safe value must leave them as a plain string does), derives item leaks across every tag with its other lists filled, its boolean flags on and off, nested items and pairs, and its list of known leaks is empty.
