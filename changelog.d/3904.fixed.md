- **An item value that is marked safe is escaped in the attributes the template tags write it to, for the list parameters the sweep derives (#3904, follow-up to #3898).** Behaviour change: an entry of a list parameter, or a value read out of an item dict, that is marked safe (`mark_safe`, a lazy one, a subclass, a `str` with `__html__`, or an object whose text form is marked safe) used to be written as it is into an attribute (`value=`, `data-*`, `id=`, `class=`, `aria-label=`, `fill=`, ...) by 43 tag parameters, and by a form field's choice value in `dj_form` (also through the native engine, which hands the form to the same tag) and the column keys and filter options of `model_table`: `audit_log` (`entries`, `columns`), `autocomplete`, `collab_selection`, `combobox` (`options`, `selected`), `cursors`, `dashboard_grid`, `data_grid` (`columns`, `rows`), `dependent_select`, `dj_select`, `export_dialog` (`columns`, `formats`), `fab`, `file_tree`, `gantt_chart`, `kanban_board` (a column and the cards inside it), `line_chart`, `masonry_grid`, `meter`, `model_selector`, `multi_select`, `notification_center`, `reactions`, `scroll_spy`, `sortable_list`, `split_button`, `tag_input` (`tags`, `suggestions`), `toast_container`, `toggle_group`, `tour`, `tree_view`, `wizard`, `theme_radio` / `theme_select` of `djust_theming`, and further parameters treated the same way. It is now escaped there exactly as a plain string is (`attr_text` in the Python tags, `|force_escape` in the three templates); text slots keep their markup. A scalar tag argument is unchanged. The template protection lives in the three shipped templates: a per-theme override or a project copy made from the old `toast.html`, `select.html` or `radio.html` must add `|force_escape` to the attribute values it prints from an item. `test_marked_safe_attribute_sweep_3898.py` now drives each of the 43 parameters (a cell each: the attributes the item reaches are pinned, and every kind of marked-safe value must leave them as a plain string does), derives the list parameters of the swept tag libraries at run time and tries each with the item's keys read from the tag, its other lists filled, its flags on and off, the scalars that select a branch set, nested items, pairs and an empty block body; a planted-leak test proves the derivation can report a leak, and a static hunt over the tag modules, the structural check of the two, finds an escaped item written to a quoted attribute (an f-string, a concatenation, `%` or `.format`; not an unquoted attribute, `format_html`, or a helper that escapes a value it is handed) without enumeration. Its list of known leaks is empty.
