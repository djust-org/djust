- **`html_update` and `html_recovery` keep the content of a `<noscript>` as text.** The page reads a `<noscript>` with scripting enabled, so its content is text, and the server writes that text as it is (#3045). The client parsed these frames with scripting disabled (`DOMParser`), which reads the same content as markup, and the morph then put those elements into the page: an `<img>` or `<a>` written inside `<noscript>` became a working element after the update. When the inert parse of a frame holds an HTML `<noscript>`, the client now parses the frame again as the mount morph does, in a detached element of the live document, which reads it with the page's scripting flag. Frames without a `<noscript>` keep the inert parse. Regression tests in `tests/js/full_html_frame_namespace.test.js`.
