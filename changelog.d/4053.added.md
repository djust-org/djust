- **System check `djust.V029`: an explicit view's event handler changes an
  attribute that is not declared state (#4053).** Under explicit exposure the
  HTTP page-POST fallback builds a new view for each event and runs `mount()`
  again, so a counter kept in an attribute set in `mount()` answered every
  fallback event from its `mount()` value, with no error (over a WebSocket it
  counted). V029 reports a direct `self.<name> = / += ...` in an
  `@event_handler` / `@action` when `<name>` is not a `state()` field, a
  descriptor, a `_private` name or one of djust's own attributes. The README and
  the getting-started, LiveView and events counters now declare
  `count = state(0, persist="server")`, which counts on every transport. New
  cases in `python/djust/tests/test_undeclared_handler_state_v029_4053.py`.
