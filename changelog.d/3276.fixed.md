- **Themed buttons and inputs show keyboard focus again (#3276).** `.btn:focus-visible` and `.input:focus` removed the outline and set `ring:`, which is a Tailwind utility and not a CSS property, so focus was invisible (WCAG 2.4.7). They now draw a real `outline` in the ring colour. The `glow` focus style of theme packs used the invalid `hsla(var(--ring), 0.3)` and is now `hsl(var(--ring) / 0.3)`. A new test scans all theming CSS for non-property `ring:`, an outline removed with no replacement indicator, and the mixed `hsla(var())` form. The same scan rejects a border-colour change or a faint halo as the only replacement indicator, so `.theme-form-*` inputs, `.theme-preset-select`, the scaffold form inputs and `*:focus-visible`, the pack `glow` style and the generated `form-input` variants also keep a real outline.
