- **AI Guardrails guide (`docs/website/guides/ai-guardrails.md`).** One page that
  lists the checks and tooling that catch mistakes an AI coding assistant makes in a
  LiveView app, with the command that runs each and what it does not cover:
  `djust_ai_context` and the `docs/ai/` pages, the MCP server's code checks, the
  `manage.py check` families with a table of the checks most relevant to generated
  code (generated from `python/djust/checks/`), the six `djust_audit` modes, and the
  framework defaults and opt-ins. The MCP server and `djust_audit` guides link to it.
