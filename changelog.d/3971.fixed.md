- **`{% status_indicator %}` is no longer a live region on every instance (#3971).** It rendered `role="status"`, so a page with one indicator per table row had dozens of polite live regions, each announced when its text changed. A label that is part of the page is not a status message (WCAG 4.1.3): the indicator is now a plain `<span>`, under both engines. `live=True` (also on `StatusIndicator`) opts the one indicator that updates in place back in.
