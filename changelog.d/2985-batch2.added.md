- **ImageLightbox, FileTree, ResizablePanel and AnimatedNumber now ship the interactions their docstrings describe (#2985, batch 2).** Each rendered a `dj-hook` that no shipped script answered; `components/static/djust_components/image-lightbox.js`, `file-tree.js`, `resizable-panel.js` and `animated-number.js` now do, and the catalogue page of each includes its script. The lightbox takes focus, traps Tab, locks page scroll, closes on Escape, steps on the arrow keys or a swipe, announces the new image and gives focus back; each of those presses the component's own Close, Previous or Next control, so it sends no event of its own. FileTree expands and collapses folders on the page and follows the WAI-ARIA tree keyboard pattern, with Enter on a file firing the row's own event; a 10,000-row tree stays responsive. ResizablePanel resizes by pointer drag or keyboard as an ARIA window splitter, clamped to `min_size` and `max_size`, and announces the size as a bubbling `dj-resize` event. AnimatedNumber counts up and always ends on the exact text the server rendered. No markup changes: a byte comparison of 564 renders across the component class, template tag and Rust handler against the previous release is identical. The scripts register in `window.DjustHooks` and only when neither hook registry already holds that name, so an app's own hook is never replaced. 12 components from the issue remain.
