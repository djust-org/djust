- **Python 3.15 and abi3 wheel evaluation (#3255).** `docs/performance/python-3.15-and-abi3-wheels-2026-10-05.md` records what blocked 3.15, the install-tested wheel matrix (cp311 to cp315 and cp314t, built the way the release workflow builds them), and measured evidence for abi3 (a `cp311-abi3` wheel built from the same tree: size, install on 3.11 to 3.15, hot-path timings against the version-specific wheels, and what abi3 cannot do). It decides nothing: the release-wheel strategy and the Python floor are unchanged. Three Unicode 17 pins in the parity tests (CPython 3.15 ships Unicode 17.0) and one CPython 3.15 change in `%`-format overflow handling are now interpreter-aware.
