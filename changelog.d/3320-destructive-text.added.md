- **`ThemeTokens.destructive_text` and the `--destructive-text` CSS variable (#3320).** A read-only token derived per preset and mode: the preset's `destructive` hue and saturation with only the lightness moved, to the nearest value that reaches 4.5:1 on the page, on a card and on the 10% and 15% destructive washes behind alerts and toasts. A `destructive` that already reads is kept exactly. It is emitted wherever the theme variables are (`:root`, `html[data-theme]`, the system-preference block), as `text-destructive-text` in the Tailwind config, `--color-destructive-text` in the Tailwind v4 `@theme` block, and in the inspector output. The contrast matrix now measures it on the background, the card and the alert tint (`CONTRAST_PAIRS`, `SOLVED_PAIR_KEYS`) in place of the `destructive` fill as text, which removes the 119 `destructive`-on-`destructive_tint` rows from the #2885 debt table (691 to 572). Custom CSS should use `hsl(var(--destructive-text))` for error text and keep `--destructive` for fills; see the accessibility guide.
