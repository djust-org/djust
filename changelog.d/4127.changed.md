- `{% nav_menu %}` / `{% nav_item %}` draw the same classes on both engines: under the Django engine a nested item now uses `dj-nav__item` / `dj-nav__link` (and `dj-nav__item--active`) at every depth, as the native handler does, instead of `dj-nav__dropdown-item` / `dj-nav__dropdown-link`. `components.css` styles a nested item as a dropdown entry by position (`.dj-nav__dropdown-list .dj-nav__item`) and keeps the `dj-nav__dropdown-item` / `-link` rules for markup that still names them. A falsy `class=` (`None`) no longer adds the class `None` under the native engine (#4127).
