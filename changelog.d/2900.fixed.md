- A class-level component's state change no longer answers `noop` (#2900): the slot that held the `State` dict before ADR-031 holds a `BoundComponent` since #2895, and every change-detection snapshot compared it by `id()`, so a handler that mutated the State through the `Meta.event` alias (a plain view event — click a tab) left the pre/post snapshots equal and the render was skipped. One rule now, `change_detection.fingerprints_by_content` + `deep_fingerprint` unwrapping the wrapper to its State, shared by `_snapshot_assigns`, the dirty baseline, `@computed` and `_sync_state_to_rust`. Pinned on the frame a real WebSocket receives. An instance-assigned component is still a leaf by `id()`.
