- **`@push_handler`: an explicit marker for a method only server push may call (#3002).** `push_to_view(..., handler="name")` reaches a marked method under any name, and a browser event naming it is refused in every `event_security` mode (`strict`, `warn` and `open`) on the WebSocket, SSE, HTTP POST and HTTP API transports, with the same response as a method that does not exist. It is not an event handler: `djust.V004` no longer suggests `@event_handler` for it, `djust.T019` reports a template binding to it in every mode, and combining it with `@event_handler` or `@server_function` is a `TypeError`. Existing `handle_*` push targets and `@event_handler` methods are unchanged. 17 regression cases in `python/djust/tests/test_push_handler_marker_3002.py`.
