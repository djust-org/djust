- **Attribute-form lazy containers are authoritative only when they are live
  in the rendered branch's authored text (#3430).** The page's literal-only
  rendering (template text and template-literal expression output such as
  `{{ "<!--" }}`, `cycle`/`firstof` literals, literal `with` bindings and
  `block.super`, with every other value replaced by U+FFFD) is parsed once with
  html5ever, and a container registers only when it is a live element there
  and in the final page. A value can no longer complete a comment, script or
  attribute that the authored text left open; ordinary output (`csrf_token`,
  `djust_client_config`, `|safe` markdown, SVG icons inside `spaceless` or
  `cache`) leaves containers working. Hiding a container with a value is not
  modelled: don't. `{% cache %}` fragments now carry their literal-only bytes;
  clear fragment caches on upgrade, as entries written before it fail closed
  until they expire.
  Captured content replays only allow-listed text transforms with literal
  arguments, and receives the page's final escaping decision, so removed or
  escaped authored closers cannot survive as stale context. Byte-changing
  unlisted transforms, including `slice`, `striptags`, fallback filters and custom
  captures, fail closed. Each value occurrence keeps adjacent literal bytes
  apart, including split comment and raw-text closers; empty page values can
  conservatively lose registration.
