- **`{% theme_preset_selector presets="legal,medical,default" %}` and `LIVEVIEW_CONFIG["theme"]["selectable_presets"]` limit the preset list (#3285).** Both take a comma-separated string or a list, in display order; the tag argument wins over the setting (`presets=""` means no limit), and an unknown name in the tag raises `ValueError`. The setting is read on every request, so a bad value never raises there: unknown names are dropped with one logged warning, all presets are listed when none is usable, and the new `djust_theming.W003` system check reports it. The setting also limits the presets in `theme_panel` and `theme_switcher` and the `theme_presets` context variable. Regression cases in `python/djust/tests/test_theming_preset_allow_list_3285.py`.
