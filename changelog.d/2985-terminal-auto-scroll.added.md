- **`Terminal` takes `auto_scroll` (#2985).** `auto_scroll=False` makes a streaming Terminal leave the scroll position alone instead of following the newest line (the default, `True`, is the behaviour before). The only markup change is an added `data-auto-scroll="false"` when it is off: the default markup is byte-identical, on the component class, the template tag and the Rust handler alike. LogViewer already had the option.
