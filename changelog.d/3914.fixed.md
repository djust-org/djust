- **A value written into a raw-text element of a hybrid component `template` is escaped even when it is marked safe (#3914).** The content of `<textarea>`, `<title>`, `<script>`, `<style>`, `<xmp>`, `<plaintext>`, `<noscript>`, `<iframe>`, `<noembed>` and `<noframes>` is text that ends at the first matching end tag, so markup in a value there can end the element. `Component.render` draws a class through its `template` when the crate constructor refuses a value (a lazy string is one) and always for a class with no crate counterpart, and that path left a marked-safe value alone: `TextArea(value=<lazy marked-safe text that ends the textarea>)` ended the element and put live markup after it. Now a `{{ }}` in the text of such an element is escaped whatever the value is marked as (a marked-safe string, a lazy one, an object whose text form is marked safe, a callable returning one; also `{{ v|safe }}` and under `{% autoescape off %}`). An ordinary value prints exactly as before: a plain name keeps the engine's formatting (a date localized, a number formatted), checked by rendering a corpus (strings, numbers, decimals, dates, datetimes, `None`, booleans, lists, dicts) before and after; a dotted path or a filtered expression ends in `|force_escape`, so a date or number there prints in its canonical form (`2026-01-02`). A tag that prints text inside such an element (`{% firstof %}`, `{% cycle %}`, `{% blocktrans %}` ...) and the templates named by an `{% include %}` / `{% extends %}` are not escaped or scanned; the existing once-per-class warning names them (class and element names only). Every OTHER text slot keeps a marked-safe value's markup, as before; the remaining difference to the Rust and custom paths for ordinary text slots is documented in the components guide and tracked in #3932. The scanner also stops reading a raw-text element at a real end tag only (`</textarea-x>` no longer ends one), and covers the elements above (it knew four). The sweep in `test_marked_safe_attribute_sweep_3898.py` drives a payload that ends every raw-text element through every hybrid template class with every claim kind, derives the raw-text slots from the shipped templates, and goes red for a pair or claim kind it does not drive.
