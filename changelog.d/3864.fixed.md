- **Safe-markup guard: every part is placed by text the guard read, or reported** (#3864). The second pass of the guard now reads the whole string a sink is handed (`_Module._misplaces`): literal text wherever it can be spelled out (each spelling of a name, a branch, a constant table or `dict.get`, a tuple, a narrowed name, `str()` / `.strip()` / `.replace()` / a slice of a literal, a class attribute, a `%` / `.format` / f-string field, a function or lambda of the file with its call's arguments), and for any other part the class of what it can do to the position (escaped text, digits, words, markup, whole attributes, or unknown). A part placed where its class may not sit, or behind a part it cannot class, is reported. Before, an earlier part it could not read counted as an ordinary character: `pre() + safe_url(x)` was cleared where `pre` returns `'<a href='` from one of two branches, a balanced fragment such as `' title="' + safe_url(x) + '"'` was placed unchecked inside a quoted or unquoted value, a helper's markup placed in a larger string was not looked into, and an HTML escaper's output between attributes or as a tag name was cleared. A function the file replaces without a `def` (`sys.modules[__name__].f = ...`, `setattr` on the module, `f.__code__ = ...`) is no longer followed. The per-builder HTML-context check this replaces is removed. Three handlers that rewrite a rendered block body at an offset are now reported and audited (`AccordionHandler`, `NavMenuHandler`, `PageHeaderHandler`). Rows, a randomized differential that runs every generated module, and a gate-off list: `python/tests/test_safe_markup_position_3864.py`, `safe_markup_position_fuzz_3864.py`, `scripts/safe-markup-position-gateoff.json`.
