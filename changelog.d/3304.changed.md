- Documented two behaviours that trip up LiveView apps: `login()` inside an event handler cannot work over the WebSocket (it rotates the session key and a WebSocket can't set the cookie that carries the new one; use an HTTP login view, the accounts pages, or `dj-trigger-action` + `trigger_submit()`), and the HTTP page-POST fallback rebuilds the view from the dict `get_context_data()` returned on the previous request, so call `super().get_context_data()` and set state in `mount()`. The template guide now says the root belongs inside `<body>`, never on `<html>` (#3304, #3292).
