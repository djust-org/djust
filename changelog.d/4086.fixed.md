- **The demo project's handlers are callable under the default strict mode and
  keep their state over the HTTP fallback (#4086).** About 80 demo handlers named
  by a template (`dj-click`, `dj-input`, `dj-submit`, `dj-change`) had no
  `@event_handler`, so the default strict mode refused them (`djust.T019`), and
  nine did not accept the parameters their event sends (`djust.T020`). Counters,
  toggles and lists those handlers read and change are declared
  `state(..., persist="server")`, so each fallback event starts from the
  previous one's value (`djust.V029`). The homepage app's six legacy views are
  explicit now (the four small demos reuse `demo_app.views.homepage`), and so is
  `CustomNavbarView`. The demo CI gate (`scripts/ci_djust_check_demo.py`) now
  also fails on any T019, T020 or V029 finding. Cases in
  `tests/integration/test_demo_declared_state_4086.py`.
