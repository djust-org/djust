- **Safe-markup guard: a sink handed a helper's call is judged with that call's arguments** (#3864, #3845). `mark_safe(tag(safe_url(x)))` of `def tag(u): return f"<a href={u}>"` and `mark_safe(helper(x))` of a helper that interpolates its argument were cleared: the guard judged the call only by its arguments. Such a call (of a `def`, a lambda bound once, or a method of a fresh instance of a plain class of the same file) is now also judged by what the function returns with its parameters bound to the call's arguments. The rule only adds findings, so everything flagged before stays flagged; a test runs the full cross product of source x helper x placement against hostile payloads and checks that nothing the previous guard flagged is now cleared (`python/tests/test_safe_markup_guard_3864.py`, `safe_markup_call_fuzz_3864.py`). The mechanisms are turned off one at a time by `scripts/safe-markup-call-binding-gateoff.json`.
