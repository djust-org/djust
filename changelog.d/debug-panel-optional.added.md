- **`DJUST_CONFIG["debug_panel"]` turns the DEBUG-only debug panel off.** Default `True`: the panel loads whenever `DEBUG` is on, as before. With `False`, djust keeps `client-dev.js` (hot reload, toasts, error overlay) but serves no `debug-panel.js` / `debug-panel.css`, no `window.DJUST_DEBUG_INFO`, no toolbar button or icon, no per-event `_debug` payload on WebSocket or HTTP responses, and `generate_sw` leaves `debug-panel.js` out of the precache list. One reader, `djust.config.debug_panel_enabled()`, gates every entry point. Useful when a development Content-Security-Policy blocks the panel's icon and inline `style=` attributes and fills the console with violations (`docs/website/advanced/debug-panel.md`).
