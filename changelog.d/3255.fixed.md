- **`@background`, the async-work runner and `track_performance` no longer call the deprecated `asyncio.iscoroutinefunction` (#3255).** CPython 3.14 deprecated it and 3.16 removes it, so on 3.14 and 3.15 each call warned and on 3.16 each would have raised. They use `asgiref.sync.iscoroutinefunction` (already a Django dependency), which gives the same answer for an `async def` and for a sync wrapper marked with `markcoroutinefunction` on every supported Python. `python/djust/tests/test_asyncio_iscoroutinefunction_3255.py` scans the package for the old spelling and runs each decorator with `DeprecationWarning` as an error.
