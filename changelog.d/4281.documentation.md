- **The 2.0 migration guide and the best-practices guide say that a page GET no longer stores the view in the state backend, so the `Large LiveView state` warning no longer fires for page loads, and where a view's size is bounded now (#4281).** The removal itself shipped in 2.0.0rc1 (the legacy Rust render cache, exposure-flip row 8). What a view persists is bounded instead: `persist="server"` fields at 64 KB, automatic state with a warning at 100 KB and a refusal at 512 KB (`state_too_large`). A budget test measures `djust.testing.persisted_state(view).automatic_bytes`.
