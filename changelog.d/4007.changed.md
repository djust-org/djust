- **The injected client is a core bundle plus chunks loaded on use (#4007).** The LiveView now injects `client-core.min.js` (~77 KB gzipped, against ~88 KB for the single bundle) and loads the uploads, virtual-list (`dj-virtual`), cursor-overlay, tutorial-bubble and service-worker modules from `static/djust/chunks/` only on pages that use them, before the client binds and connects; a page that uses none loads none. Each chunk `<script>` carries the client tag's CSP nonce, and its URL comes from `static()` (hashed names under `ManifestStaticFilesStorage`). `djust.uploads` and `djust.registerServiceWorker()` work as before: until the chunk loads they are stubs that load it and forward. A view that declares uploads loads the uploads chunk when it mounts. A page that gains `dj-virtual`, `dj-hook="CursorOverlay"` or the tutorial bubble only after init (through a patch or `live_redirect`) needs `LIVEVIEW_CONFIG = {"client_bundle": "full"}`, which injects the single `client.min.js`; a hand-written `<script src="{% static 'djust/client.js' %}">` keeps loading the full bundle. See the [client bundle guide](docs/website/guides/client-bundle.md).
