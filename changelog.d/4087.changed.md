- **`djust_exposure_inventory` reports where a legacy view's state goes on 2.0
  (#4087).** The `render_cache` destination is gone, and `session_state` and
  `private_session` are now always listed as conditional: 2.0 writes a legacy
  view's state to the session only when it renders as a `lazy=True` child and an
  event reaches it over the HTTP fallback. Before, the report still described
  the 1.x render cache and the page's `liveview_<path>` session copies. Cases in
  `python/djust/tests/test_exposure_inventory_command.py`.
