- **`dj-input` is no longer described as firing on every keystroke (#3356).** The template cheatsheet, `dj-paste`, `live_input`, best-practices and `docs/ai` pages, `llms-full.txt` and the schema description (which feeds the generated AI-context files and `djust_schema`) now say what the client does: text-like fields are debounced 300 ms by default, `range` and `color` are throttled 150 ms, `number` 100 ms, checkbox, radio and select send immediately, and `dj-debounce` / `dj-throttle` override it (`dj-debounce="0"` sends every keystroke). The pins in `python/djust/tests/test_schema_directive_pins_3327.py` read the client's rate-limit table and each doc, so the wording cannot drift from the code again.
