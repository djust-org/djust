- **`djust.B008` is a deploy check, and djust's `collectstatic` runs it first (#3144).**
  B008 lists every static file to find a `*.cdx.json`, `*.spdx.json` or
  `*.bom.json` that `collectstatic` would publish. It ran on every
  `runserver` start, every autoreload and before `migrate`, which is a full
  walk of `STATICFILES_DIRS` each time. It now runs under
  `manage.py check --deploy` and as part of djust's `collectstatic` system
  checks, which stop the command before anything is collected (unless
  `--skip-checks` is passed). Detection is unchanged; it no longer runs on
  ordinary check runs.
