- **Constant inline styles and an inline script no longer need `'unsafe-inline'` (#4139).**
  The constants #3979 left inline, which a strict Content-Security-Policy refuses, are now
  the `hidden` attribute or a class in every mode, with JavaScript off and at first paint:
  the data table's hidden triggers and import input (`{% data_table %}` on the Rust engine),
  the data grid's edit trigger, a collapsed `{% file_tree %}` / `FileTree` folder, the
  connection-status bar and the scroll-to-top button (tag and class), an inactive pane of
  the plain `TabsComponent`, and the theme modal and dropdown (`hidden`, toggled by
  `connection-status.js`, `scroll-to-top.js`, `file-tree.js` and the theming
  `components.js`); a clickable data-table row's pointer cursor
  (`data-table-row-clickable`); the Bootstrap modal (`d-block`) and navbar menu
  (`d-flex`). The dismissible Bootstrap badge's close button, the Bootstrap navbar's
  external link and the Bootstrap sortable table headers keep their inline style by
  default and use `dj-badge-close` / `dj-navbar-link--external` / `dj-sortable-th` under
  `LIVEVIEW_CONFIG["csp_strict_styles"]`. The ttyd terminal registers its hook from the
  static module `python/djust/components/static/djust_components/ttyd/register.js` instead of an inline module script.
  `{% djust_pwa_head %}` (on both engines) and the theme context processor's
  `theme_switcher` carry the request's CSP nonce; the switcher's inline `onclick` /
  `onchange` handlers are the `data-theme-mode` / `data-theme-preset-select` attributes
  `theme.js` handles. The accessibility report's score no longer floats by an inline
  style. `djust new` projects link `<app>/static/<app>/app.css` instead of an inline
  `<style>` and inline `style` attributes. New: `scripts/template-library-csp-sweep.py`,
  which renders every tag on both engines and every component class in both modes and
  reports what a strict CSP refuses; its test and one test per site are in
  `python/djust/tests/test_csp_constant_styles_4139.py`, the client side in
  `tests/js/csp_constant_styles_4139.test.js`.
