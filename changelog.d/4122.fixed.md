- **A LiveView template whose wrapper opens in one `{% if %}…{% else %}` and closes in another renders (#4122).** The `dj-root` extraction balanced `<div>`s across `{% if %}` branches and, after an `{% else %}` reset the depth, took the wrapper's `</div>` inside the second `{% if %}` for the root's close. The truncated source then failed with a misleading "Unclosed tag 'if'" (or, with `{{ block.super }}` in the base, a `BlockNode` error). A close inside a branch is no longer read as the root's close.
