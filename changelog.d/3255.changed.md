- **The Python 3.15 CI cell can install its dependencies and pass its tests (#3255).** All four `py3.15` shards failed in `uv sync` before any test ran: fourteen locked packages had no `cp315` wheel and were built from source, and the Rust ones (`rpds-py`, `watchfiles`) were refused by their old PyO3 ("newer than PyO3's maximum supported version (3.14)"). `uv.lock` now carries versions with `cp315` wheels (`cffi`, `librt`, `msgpack`, `orjson`, `rpds-py`, `ujson`, `uvloop`, `watchfiles`), and the dev extra pins `pydantic>=2.14.0b2` for Python 3.15 only, because `pydantic-core` has no `cp315` wheel before the 2.48 series that only pydantic 2.14 (still a beta) pulls in. Python 3.11 to 3.14 keep their existing `pydantic`. `autobahn`, `httptools`, `pyyaml`, `zope-interface`, `zstandard` and, on macOS, `watchdog` still build from source on 3.15 (C extensions, a few seconds each). The Rust extension itself builds on 3.15 with PyO3 0.29.2 unchanged. The `py3.15` cell stays allow-failure until 3.15.0 is final.
