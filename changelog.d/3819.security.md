- **A `{% live_render %}` lazy placeholder is escaped unless it is marked safe, and the JSON inlined in a `<script>` is script-escaped (#3819).** `lazy={"placeholder": ...}` was spliced into `<dj-lazy-slot>` as raw HTML with no stated contract, so a placeholder built from data injected markup. It now follows Django's own rule (`conditional_escape`): a marked-safe value (`mark_safe`, `format_html`, anything with `__html__`, a lazy marked-safe string) is markup and is spliced in as written, a plain `str` is text and is escaped. Behaviour change: a project that passed `"<div>Loading...</div>"` must wrap it in `mark_safe(...)`; the contract is documented in the streaming-render guide. `routing.get_route_map_script` put `json.dumps(routes)` inside a `<script>` with `mark_safe`, on the argument that URL config cannot hold `</script>`; `json.dumps` leaves `<`, `>` and `&` raw and nothing enforced that argument, so it now passes the JSON through `escape_json_for_script` (the helper the debug panel and the PWA tags use). The same one-line fix applies to the two other developer-config blobs inlined in a script: the handler-metadata script (`window.handlerMetadata`) and `window.DJUST_LOADING_GROUPING_CLASSES`. Output is byte-identical for any value with none of `<`, `>`, `&`, U+2028, U+2029. `python/tests/test_raw_slots_3819.py` and the payload sweep (`live_render` is now given a hostile plain-str placeholder), gate-off verified.
