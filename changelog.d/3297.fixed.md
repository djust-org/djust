- **`manage.py djust_ai_context` no longer overwrites an existing file silently.** It opened its target with `open(path, "w")`, so a hand-written `CLAUDE.md`, `.cursorrules` or Copilot instructions file was replaced by the generated file with exit status 0 and nothing of the original left. It now raises a `CommandError` (exit status 1, file untouched) when the target exists, naming `--force`, `--output` and `--print` as the ways forward; `--force` replaces the file as before, and `--print` is unaffected. No backup or marker-section merge: the generated file is meant to be regenerated whole, so the safe default is to refuse. The command is documented in the Scaffolding guide (#3297).
