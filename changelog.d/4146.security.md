- **djust writes no inline event handlers of its own (#4146).** A Content-Security-Policy whose
  `script-src` lacks `'unsafe-inline'` refuses every `on*=` attribute, and no nonce can allow
  one. The four djust wrote are now markers handled by a listener on `document`, which also
  covers markup a LiveView patch inserts later, with the same behaviour: `NavBar`'s menu toggle
  (Tailwind and plain renderers) is `data-navbar-toggle` / `data-navbar-toggle-class`, handled
  by the new `python/djust/components/static/djust_components/navbar-toggle.js`, which the navbar loads itself with a
  `<script src defer>` inside its `<nav>` (no page setup); the close button of
  `{% theme_alert dismissible=True %}` and `{% theme_toast %}` is `data-theme-dismiss`, handled
  by `python/djust/theming/static/djust_theming/js/components.js`, which `{% theme_head %}` loads. A page rendered with
  `{% theme_head include_js=False %}` must load that script itself for the button to work; the
  new system check `djust_theming.W005` reports a project that renders one of the two tags,
  turns the script off and loads it nowhere. A caller's own `onclick=` on `{% theme_button %}`
  and the `Button` component is kept and documented (a strict policy refuses it; use `dj_click`
  or a JS command); `{% theme_button %}` now escapes it even when it is marked safe, so a
  template literal such as `onclick='go("a")'` is one attribute (it closed the attribute at its
  first `"` on both engines). The CSP sweep exercises that caller-supplied `onclick=` and fails
  on any other handler in both modes. The `data_table` `row_url` docstring no longer describes
  an inline handler the table stopped writing in #3887. Security guide: "Inline event
  handlers".
