- **`dj-submit`: the pressed submit button is lost under strict event parameters (#3958).** `_target`, its only channel, is never generated under the strict policy (ADR-036 decision Q2), and the button's own `name=value` was never a field. Under strict the pressed button's `name=value` is now a generated form field, as on a native post, and follows Q1 like every other generated value: it is sent only to a handler that declares that parameter or has a `**` catch-all, so naming a button cannot add a parameter to a closed handler. An unnamed button, a submit with no submitter, and a name no handler could declare (`save-draft`) send nothing. Legacy handlers are unchanged (`_target` stays the channel and no field is added, since a legacy closed signature rejects an unexpected parameter). Covered by `tests/js/submit_submitter_3958.test.js`.
