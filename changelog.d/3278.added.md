- **The theming layouts can host a LiveView base template (#3278).** The base layout gains `{% block body_attrs %}` (attributes on `<body>`) and `{% block client_config %}` (in `<head>`, for `{% djust_client_config %}`), and each layout that wraps its content in `<main>` gains a block around that whole element (`sidebar_topbar_main`, `sidebar_main`, `topbar_main`, `centered_main`) so a page can supply its own `<main dj-root>` without nesting two. With no block overridden every layout renders byte-for-byte what it did before. Regression cases in `python/djust/tests/test_theming_layouts_blocks_3278.py`.
