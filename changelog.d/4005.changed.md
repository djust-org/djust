- **Eleven more rarely used built-in filters run Django's own function (#4005).**
  `cut`, `last`, `random`, `default_if_none`, `escape`, `escapejs`,
  `dictsort`, `dictsortreversed`, `ljust`, `rjust` and `center` now call
  `django.template.defaultfilters.<name>` instead of a Rust port. They stay
  built-ins (no `{% load %}`, the same parse-time checks), and their output,
  escaping and exceptions are Django's own; `random` draws from Python's
  `random`, so `random.seed()` governs it as in Django. djust's guards stay in
  front of the call: `ljust` / `rjust` / `center` still refuse a width past
  1,000,000 with the same message before Python is asked to allocate it, and
  `dictsort` / `dictsortreversed` still walk a generator or other one-shot
  iterable through the 100,000-item cap and read a model through its floor
  proxy. `last`, `random`, `dictsort` and `default_if_none` hand back the
  context's own values, so `{% with x=rows|last %}{{ x.name }}` keeps
  working. `force_escape` stays native: every hybrid-template attribute slot
  ends in it, so it is no longer cold.
