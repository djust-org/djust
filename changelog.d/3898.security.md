- **Marked-safe values are no longer exempt from the URL scheme check; the no-op `javascript:void(0)` / `javascript:;` hrefs are still accepted (#3898, #3894).** Behaviour change: a `mark_safe` (also lazy, or `__html__`) value used as a URL in a component (the class-based components, the template tags' item data and their own keywords such as `{% avatar src=... %}`) is now checked against the scheme allowlist and escaped like any other string (an already-escaped `&amp;` is escaped once more, so pass the plain URL), and an item value that lands in an attribute (`alt`, `title`, `id`, `data-*`, a class, `model_table`'s `dj-value-row`) is escaped whatever it is marked as. Text slots keep their markup. The literal no-op hrefs `javascript:void(0)` and `javascript:;` (exact text, `href` only, never an image source) are accepted marked or not, so a dropdown toggle needs no `mark_safe`. URL helpers convert values to the exact `str` type before checking them. `test_marked_safe_attribute_sweep_3898.py` derives the components, parameters and tags from the code and fails on any URL call that leaves `honor_safe` at its default.
