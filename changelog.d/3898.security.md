- **A marked-safe value read out of a component's data is checked and escaped like any other (#3898, #3894).** The class-based components (their constructor arguments and item dicts) and the template tags that read a URL out of an item or a list (`carousel`, `avatar_group`, `chat_bubble`, `activity_feed`, `data_card_grid`, `org_chart`, `rich_select`, `sortable_grid`, `lightbox`, `mentions_input`, ...) now pass every URL through `data_url_attr` and every item value that lands in an attribute through `attr_text` (`django.utils.html.escape`): `mark_safe`, a lazy marked-safe string and `Markup` no longer skip the scheme allowlist or the escaping there. A marked-safe value in a text slot is unchanged, and a template tag's own keyword argument (`{% avatar src=... %}`) still honours it. `test_marked_safe_attribute_sweep_3898.py` derives the components, parameters and tags from the code, and pins the call sites that still honour a marked-safe value so a new one fails until it is decided.
