- `T019`-`T022` now run when `TEMPLATES` lists only `DjustTemplateBackend` (the `djust new` default). They previously did nothing, silently, because no Django template engine was found; a compile-only engine is now built from the Djust backend's directories, libraries and builtins. When no template engine is configured at all, a new info message `djust.T023` says the checks were skipped (#3299).
