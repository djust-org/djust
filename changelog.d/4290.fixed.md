- **Explicit exposure no longer hands the renderer every field of a Model or row list the template reads only columns off.** A top-level Model, model list or QuerySet whose relations the template does not walk now goes through the template-path JIT, as on 1.x, so the renderer's state (and its snapshot) carries the fields the template names, not every concrete column less `djust_exclude_fields`. A Model the template reads nothing off keeps only its identity keys; a row list read with no field path (`{% regroup %}`, `{{ rows.0 }}`) keeps whole rows, as the JIT gives it (#2736). A `dictsort:<variable>` naming a non-column keeps the normalized rows. The migration guide notes the change (#4290).
