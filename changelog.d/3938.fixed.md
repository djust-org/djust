- A `{% blocktranslate ... asvar name %}` variable printed as `{{ name }}` in an attribute, `<textarea>` or `<title>` of a component's inline template is escaped exactly once, as Django prints it (`Delete A &amp; B`, not `Delete A &amp;amp; B`), and a marked-safe variable of the block is escaped instead of ending the attribute. Where the slot may not read that block (the block inside `{% if %}` / `{% for %}` / `{% with %}`, the name bound twice, `{% extends %}`) or the slot is filtered, the text is still escaped twice. (#3938)
