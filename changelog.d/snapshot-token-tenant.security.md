- **The signed `state_snapshot` token of a `TenantMixin` view is bound to its tenant.** A back-navigation token (`enable_state_snapshot = True`) was bound to the view and the session; it is now also bound to the tenant that minted it. A mount under a different tenant refuses it and runs `mount()` fresh, and a tenant view with no resolved tenant neither mints nor accepts one. Views without `TenantMixin` are unchanged. Tokens that tenant views issued before the upgrade are refused once (one fresh mount, then a new token). `ModelFormMixin` now chains `_djust_render_only_context_keys()` through `super()`, so listing it before `TenantMixin` keeps the `tenant` key render-only (#3328).
