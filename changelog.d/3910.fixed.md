- `{% for u in users|dictsort:key %}` with the field name in a context variable rendered an empty loop over QuerySet and `list[Model]` rows, because the rows held only the fields the template names. The JIT now resolves the variable from the render's context and adds the one column it names to each row (a key that changes between renders serializes its own column), so a key naming one of the model's own columns sorts as Django sorts. A key naming a property, a method or a relation path still renders an empty loop, and so does a column the serialization floor or `djust_exclude_fields` hides, where Django sorts.
