- `{% for u in users|dictsort:key %}` with the field name in a context variable rendered an empty loop over QuerySet and `list[Model]` rows, because the rows held only the fields the template names. Each row now also carries the model's own non-relation columns (from the floored whole-row serialization, nothing it computes), so a variable key naming a column sorts as Django sorts; one naming a property or a path through a relation still renders an empty loop.
