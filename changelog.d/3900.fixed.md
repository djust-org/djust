- **A `Component`'s hybrid `template` now applies the attribute rule of the Rust instance and `_render_custom()` to its attribute values (#3900).** `Component.render` draws a class that has a `template` through it when the crate constructor refuses a value (a lazy string, `gettext_lazy` / `format_lazy`, is one; so is any object that is not plain text) and always when the class has no crate counterpart (`ButtonGroup`, `Checkbox`, `Input`, `Offcanvas`). That path wrote `{{ src }}` into an attribute with only autoescape and no URL check, so `Avatar(src=<lazy "javascript:alert(1)">)` printed a live script URL where the plain string printed `<img src="#">`, and a lazy `size` / `status` could leave its attribute. Now every `{{ ... }}` in the value of an attribute of a start tag is escaped whatever the value is marked as, however it yields its text (a marked-safe string, a lazy one, an object whose text form is marked safe, a callable the engine calls), also under `{% autoescape off %}`; and in a URL attribute (`href`, `src`, `action` ..., and the `dj-navigate` / `dj-patch` / `dj-patch-reload` directives) the value is judged with the scheme allowlist the other paths use (`url_allowed`, `data_url_attr`, `srcset_attr`), so any scheme outside the allowlist (`javascript:`, `data:` for a link, `sms:`, `magnet:` ...) becomes `#`. The template is read once per template string (a bounded LRU cache) with the HTML attribute grammar (whitespace around `=`, quoted and unquoted values), so it covers the 19 shipped hybrid classes and a template you write yourself. Behaviour changes for your own hybrid components: a marked-safe value in an attribute is escaped again (`mark_safe("a &amp; b")` prints `a &amp;amp; b`; pass plain text); in an attribute a number prints in its canonical form (`33.5`, not a localized `33,5`) and a date in its ISO form (`2026-01-02`, not a localized `Jan. 2, 2026`), for a plain name, a dotted path and a filtered expression alike; a callable that needs arguments prints nothing, as in Django; and the hybrid path is now stricter than `_render_custom()` for a scalar argument in a non-URL attribute. A URL is judged as the WHOLE value in every way it can come out: a literal inside `{% if %}` / `{% for %}` may be skipped, so it never fixes the value (each branch is a path of its own, and a good value that follows a block-added literal is judged as if the block were skipped), and a literal is read the way a browser reads it (character references decoded, tab and newline dropped). A slot that can still choose the scheme (first in the value, or only scheme characters before it) is judged together with the literal text and the other slots; a slot after a top-level literal that already fixes the value (`href="/search?q={{ q }}"`, `href="http://{{ host }}/"`, `href="{% url 'x' %}?q={{ q }}"`) is escaped, not judged, so `foo:bar` and `host:port` are kept. A URL value that can choose the scheme but whose slot is a dotted path, a filtered expression, a `{% for %}` / `{% with %}` variable, sits beside a tag that prints text this module does not follow (`{% trans %}`), has more than 64 paths, or has an attribute NAME built by tags, is escaped but not judged; a `srcset` is judged only when the slot is the whole value; an unquoted value is escaped but cannot be made safe. Each of these is named by one warning per component class and set of attributes, which carries the class name and the tag / attribute names only, never template text. A value whose `str()` raises raises in a URL slot as the engine does; in a plain slot the Rust engine's `force_escape` prints the escaped default repr where Django's raises (the crate's filter, unchanged). `{% verbatim %}` and `{% comment %}` blocks, `{{ }}` in an attribute name and text between tags are left as written. The sweep in `test_marked_safe_attribute_sweep_3898.py` no longer sets the hybrid cells aside: it drives every template class through the template and through `Component.render`, with a claim for each kind of value, and its reach test asks per claim kind.
