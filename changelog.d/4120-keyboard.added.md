- **`{% kanban_board %}` cards can be limited to the columns they may move to, and move by keyboard (#4120).** A card's `targets` (column ids) renders as `data-targets`; while the card drags, only those columns take a drop and are marked `kanban-col-target`, so the browser shows no drop elsewhere. The server still checks the move. Every card takes focus: Space picks it up, the arrow keys choose an allowed column, Enter or Space drops it there and sends the same `move_event` as a drag (over WebSocket, SSE or the HTTP fallback alike), and Escape or moving focus away cancels; each step is announced in a polite live region. The markup contract in the components guide lists `data-targets` and the new classes.
