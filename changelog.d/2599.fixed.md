- **`use_actors=True` views mount on their own template instead of an empty document (#2599).** `SessionActor::handle_mount` built its `ViewActor` with `ViewActor::new`, whose backend carries an EMPTY template, so every actor mount frame was `<html><head></head><body></body></html>`. The mount message now carries the template source and template dirs (`SessionActorHandle.mount(..., template=, template_dirs=)` → `mount_with_template` → `ViewActor::with_template_and_dirs`), and `ViewRuntime.dispatch_actor_mount` passes `view.get_template()` + `get_template_dirs()`. Pinned over a real `WebsocketCommunicator` actor mount asserting the rendered template body.
