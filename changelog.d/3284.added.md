- **`{% theme_head %}` puts a CSP nonce on its inline `<script>` and `<style>` blocks (#3284).** The nonce is `request.csp_nonce` when django-csp sets one, or `{% theme_head nonce=request.csp_nonce %}`; `nonce=""` disables it and an explicit value wins over the request. With no nonce the output is unchanged, and the script is otherwise byte-identical. `build_theme_head_context()` gains a `nonce` argument and returns a `nonce_attr` key. Known limit: the deferred-stylesheet `<link>` still uses an inline `onload`, which a nonce does not authorise. Regression cases in `python/djust/tests/test_theming_head_nonce_3284.py`.
