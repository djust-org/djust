- **`DjustTemplateBackend` now accepts `OPTIONS['autoescape']` (Django parity; #2665).** Previously refused with `ImproperlyConfigured`. The default is unchanged — escaping stays on unless a project writes `'autoescape': False` into its own `TEMPLATES` OPTIONS, and context keys still cannot configure it. Stated as a deliberate policy reversal in `docs/SECURE_DEFAULTS.md` so it is not mistaken for drift; the writer-set pin was rewritten rather than removed.
