- **`{% stepper %}` steps are keyboard-operable buttons in an ordered list (#3970).** Under the Rust engine each step was a `<div dj-click>`: not focusable, no role, the current step unmarked, "completed" only a CSS class. All three renderers (the Django tag, the native handler and `Stepper`) now render `<ol class="stepper">` of `<li class="stepper-step">`, each holding a `<button type="button">`; the current step is `aria-current="step"` and a completed step that is not current adds a visually hidden "(completed)". If you restyle `.stepper-step` as a button, move those rules to `.stepper-step-button` (the `<li>` is now the flex item). Cases in `TestStepper` of `python/djust/tests/test_component_aria_v1_3_0_19.py`.
