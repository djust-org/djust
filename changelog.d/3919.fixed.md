- `dictsort` with a key naming a method or a related manager (`dictsort:'get_full_name'`, `dictsort:'groups'`) sorted the rows by the called value, where Django orders the uncalled objects, fails, and renders an empty loop. Such a key is now left out of a JIT row when nothing else in the template reads it, and a live object's method or manager is not a sort value, so every entry renders what Django renders (with one row, Django renders it and djust still renders nothing).
