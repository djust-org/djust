- **Breaking (test helper): `LiveViewTestClient.mount()` runs the pre-mount auth
  every transport runs (#4073).** It called `mount()` without the
  `login_required` / `permission_required` / `check_permissions()` checks and the
  tenant resolve (`djust.auth.core.run_pre_mount_auth`), so a test could mount a
  view as a user the HTTP GET and the socket refuse. A refused user now raises
  `PermissionDenied`, and an anonymous user on a `login_required` view raises the
  new `djust.testing.MountRedirect` (its `url` is the login URL); `mount()` does
  not run and the client is not mounted. A test that mounted a gated view without
  a user must now pass `user=` (or set `"user"` in a `LiveViewSmokeTest`
  `view_config`). New cases in
  `python/djust/tests/test_testclient_pre_mount_auth_4073.py`.
