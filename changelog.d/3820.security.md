- **The safe-markup guard (`scripts/lib/safe_markup_taint.py`) now follows a name's flow, narrows on membership tests, trusts the project's own escapers by origin and in the position they are clean in, and sees the two `mark_safe` wrappers `_safe` and `safe_html`; the #3774 audit list shrinks from 199 flagged sinks to 55 (#3820).**

  Over `python/djust` the guard flagged 125 sinks (#3774 audited and kept 96 of them in 93 functions, mostly its own limits). It also could not see `_safe(...)` (about 190 call sites in `components/rust_handlers.py`) or `djust._html.safe_html(...)`, so a new `def f(v): return safe_html(f"<div>{v}</div>")` passed the guard, the audited baseline and the payload sweep alike. Both are sinks now, and so is any function the guard finds, by data flow, to mark one of its parameters safe (`def _ms(v): x = v.strip(); return mark_safe(x)`, a lambda, a `partial`, `str(v)`, `*args`), and a test names every such wrapper in the package. With the wrappers the first guard flagged 199 sinks; the guard as it is now flags 55 in 51 functions. 144 of the 199 are proved by the guard and their audit entries are deleted rather than kept; 15 sinks in 14 functions were read by a person and are recorded in `scripts/lib/safe_markup_audit.py` with a reason and evidence (verdict S: read and traced, not proved). This is a statement about what the guard can prove, not a claim about the sinks it cannot: the guard has known false negatives, listed in its docstring and in one issue.

  What the guard learned, each rule shown by a dirty shape and its clean twin in `python/tests/test_safe_markup_guard_3820.py` and `test_safe_markup_guard_3848.py`: **flow** (`width = int(width)` leaves `f"{width}"` clean; a coercion in only one branch, past a `continue` / `break`, in a loop that comes back round, in a `try` body whose handler runs, in an earlier `except*` handler, in a `with` that can swallow, after a `+=` / `append`, in a closure, `global`, `nonlocal`, `:=`, `finally`, `import` / `match` rebinding or beside `locals()` does not); **narrowing** (`x in CONSTANT`, `x == "a"` and `isinstance(x, int)` clear `x` on the branch where they hold, from either edge; `x == other` narrows nothing, and neither does a collection that anything in the file changes in place (`.append`, `.update`, `.setdefault`, `D[k] = v`, `|=`, `__setitem__`, through `self.X`, `cls.X` or an alias), declares `global`, or hands on (`a = D`, `f(D)`, `return D`), the wrong edge, or `assert`); **the project's escapers**, trusted by the module that DEFINES them, never a re-export or a same-named twin or an import the file rebinds (`safe_url`, `url_attr`, `srcset_attr`; `safe_css_color` / `_length` / `_ratio` / `_number` when their `default` is clean and no `*args` / `**kw` hides it; the record builders `upload_attrs`, `voice_extras`, `map_picker_attrs`, `pad_extras`, `cropper_extras`, `menu_attrs`, `clamp_columns`, `clamp_cells`, `rich_html`, `render_markdown`), each pinned by a hostile-payload test of its contract. A value-escaper's output is clean in element text or a QUOTED attribute value and not in an unquoted attribute (`<a href={safe_url(x)}>` keeps its spaces); `escape_json_for_script` is clean only for `json.dumps` output in `<script>` text (it leaves `"` alone); `attr_name` is not cleared at all (`onmouseover` is a legal name); **class tables and constants** (`self.ICONS.get(k, "")`) are trusted only when nothing writes them: not under `setattr`, `__dict__`, `__setattr__`, `vars`, `globals()` anywhere in the file, not in a class that inherits (across the package) from one that writes its constructor keywords with `setattr` (`Component`), not when the table is changed through `self` / `cls` / an alias, not in a dataclass-style annotated field, and not when a class of the same file overrides them; **`d.get(k, DEFAULT)`**, **calls to a helper the file defines** (judged by what it returns, with its parameters raw; not when `global` or `setattr` can replace it, and a bare name in a method is the module's, not the class's), `sum` / `max` of clean values and comprehensions of them, **a Rust handler's block `content`**, which the engine hands over as a `SafeString` (checked against the compiled engine), and a depth bound that FLAGS a chain it cannot follow instead of clearing it.

  Found while teaching it: `TABLE.get(key, default)` was judged by the table only, so a raw `default` came out clean (no site in the tree used it). Fixed, and pinned with the rule switched off. Three tag modules (`_advanced.py`, `djust_components.py`, `_forms.py`) imported `safe_url`, `_dev_tools.py` imported `conditional_escape` and three call sites imported `escape_json_for_script` through a re-export, which the guard rightly did not trust (the #3774 lesson); they import from the defining module now, and `TestNoEscaperIsImportedThroughAReExport` is the lint that finds the class without running the guard.

  The flow analysis is checked against real execution: a differential fuzz generates random functions, runs them with a marker as the raw value, and fails when a `mark_safe` that received the marker was not flagged (no false negative in 40 000 programs across 16 seeds). 57 unsafe functions from an independent review's corpus are RUN (each must emit the payload raw) and flagged; 27 of them the earlier head of this change had stopped flagging and are regression-tested by name. Twenty-two deliberately broken analyses (a loop that forgets its `break` / `continue` states, an `if` that follows one branch, a merge that keeps the first path, narrowing on the wrong edge or against any expression, an `assert` that narrows, an exception that sees only the state before the `try`, a helper that is always clean, hazards that are not found, a read from another scope that is always vouched for, a class body visible to its methods, a depth bound that fails open, ...) are each caught by the fuzz or a directed row. The payload sweep now also drives the Rust-native handlers and parses what they print. The safe-markup baseline check is on `make merge-gates` (`test_safe_markup_gate_3848.py`), because two PRs can break it together.
