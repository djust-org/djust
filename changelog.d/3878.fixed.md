- **A raw-body block tag nested in itself rendered half its body (#3878).** The Rust parser ended a
  raw-body tag's body at the FIRST matching end tag, so `{% accordion %}` (or `{% tabs %}`,
  `{% filter_bar %}`, ...) inside the same tag's body left the outer end tag over as
  `Invalid block tag`. The body now ends at the end tag that closes the tag, as Django's own
  `parser.parse` does (`collect_nested_raw_source` in `crates/djust_templates/src/parser.rs`).
