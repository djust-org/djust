- **A native component handler uses an explicitly passed argument as given, even when it is empty.** `data_table` (`rows`, `columns`), `breadcrumb`, `stepper`, `dj_select`, `dj_radio`, `autocomplete` and `dependent_select` now let an explicit argument win over a context variable of the same name; the render context is consulted only when the argument is absent (the handlers' documented convenience, unchanged). An argument that resolves to nothing counts as passed: `{% breadcrumb items=nope %}` draws empty, as the Python tag does, where it used to fall back to `breadcrumb_items`. A structural test scans the handler modules for the previous shape.
