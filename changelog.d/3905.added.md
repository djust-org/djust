- **`scripts/gate_off_batch.py` / `make gate-off-batch`: a gate-off over many sites in one full test run per batch, not per site (#3905).** It applies every mutation of a batch at once, runs the whole test command once, and attributes each failing test to a mutation by the text of its failure (a declared `names` substring or a `test_ids` regex). A test claimed by two mutations, a failure nobody claims, a batch that does not collect, hangs or runs away is never guessed onto a member: the affected mutations are re-run alone. It reuses `scripts/gate_off.py` for the bounded run (HUNG and RUNAWAY-MEMORY are `CAUGHT` with the measurement), the directory lock and journal, the SHA-256-verified restore and pytest classification (errors counted; a module that did not import is `INVALID`), and adds a clean-tree guard, `--survivors-only`, `--verify-survivors` and `--jobs 2`. Documented in `docs/testing-strategy.md`; the tool is itself gate-off'd in `scripts/gate-off-batch-selfcheck.json`.
