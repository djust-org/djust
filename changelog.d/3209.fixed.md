- **Theme colours that browsers silently dropped because a bare HSL token was
  used as a colour (#3209).** Theme tokens are bare HSL triplets
  (`--link: 28 80% 35%`), so `color: var(--link, var(--primary))` computes to a
  string that is not a colour and the declaration is discarded. Every such use
  now goes through `hsl()`: `.page-link` and the auth-page footer links (the
  cited `pages.css:70` and `:87`), plus nine more in `pages.css` (page title,
  descriptions, back link, error code, ETA, social divider), the catalogue's
  `.dc-version`, the outlined button's hover text in `theme_css_generator.py`,
  and `.hover-glow`'s `rgba(var(--primary) / 0.3)` in `design_system_css.py`.
  `python/djust/tests/test_theming_hsl_token_usage_3209.py` scans every
  stylesheet, template and CSS-emitting Python file in the package and fails on
  a bare `var(--<token>)` outside `hsl()`/`hsla()`; the token list is read from
  the theme generator's own output.
