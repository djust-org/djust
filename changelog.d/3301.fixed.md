- djust WARNING and ERROR records now reach stderr in a project with no `LOGGING` config. The observability ring-buffer handler on the `djust` logger had suppressed Python's last-resort handler, so warnings such as the root-on-`<html>` and template-inheritance fallback messages were silent. The handler now hands WARNING+ `djust.*` records to `logging.lastResort` only when no other handler on the logger's propagation chain would receive them, so a configured project does not print twice and INFO stays quiet (#3301).
