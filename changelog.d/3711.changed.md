A complexity claim ("linear on tag soup", "bounded") is now judged by growth with `djust.tests._growth.assert_scales_linearly` in `python/djust/tests/_growth.py` (four times the input must cost under ten times as much, interleaved, best of three, on this thread's CPU time), and a "did not block" claim by an ordering (a test-owned event, a frame received while another call is still blocked). `python/djust/tests/test_no_absolute_time_bounds_3711.py` finds the shape by AST and lets the per-file count only fall; its baseline is empty. It follows `elapsed = _took(fn)` and `self._took(fn)`, `budget_ms = ...`, `await helper()`, `datetime.now()` / `timezone.now()` spans, `loop.time()` however the loop is named, aliased clock imports (`from time import perf_counter as pc`, `import time as t`, `from time import time`), `assertLess` / `assertLessEqual` / `assertGreater` / `assertTrue`, `if elapsed > N: raise` / `pytest.fail`, `assert not elapsed > N`, module-level asserts and the walrus, with a positive test per variant.
