- **Everything djust 2.0 removes now warns first (#3500).** Each warning goes
  through `warn_deprecated`, names its replacement and says it is removed in
  `2.0.0`; `docs/API_STABILITY.md` lists them all.
  - `AccordionMixin`, `TabsMixin`, `ModalMixin`, `CollapsibleMixin`,
    `SheetMixin`, `DropdownMixin`, `TooltipMixin` and `CarouselMixin` warn when
    a view subclasses them. Use the matching component in
    `djust.components.descriptors`.
  - `@reactive` warns where it is applied. It cannot work on a `LiveView`,
    which has no `update()` (the decorator raises `TypeError` there), and on
    other hosts the decorated function's body is never called. Use a plain
    attribute or `@computed`.
  - `social_auth_providers` (deprecated in 1.3) now warns in the standard form,
    with a removal version.
  - `@event`, `LiveViewForm` and the `_legacy` theme module, whose warnings said
    "no earlier than 1.1.0", now name `2.0.0`.
  - The module shims `djust.template_backend` and `djust.state_backend` warn
    on import, `djust._view_resolution.is_view_import_allowed` and
    `djust.rust_components.Button` warn when called, and
    `djust.simple_live_view.LiveView` warns on access. The scaffolder, the
    framework's own imports and the test suite use the real paths.
  - The SSE `/event/` endpoint (`DjustSSEEventView`) warns on each POST.
  - `StreamingMixin`'s async `stream_insert` / `stream_delete` gain the names
    `astream_insert` / `astream_delete`. On a `LiveView` the old names were
    shadowed by the sync collection-stream methods and reachable only as
    `StreamingMixin.stream_insert(self, ...)`, which now warns.
  - At startup, `DjustConfig.ready()` warns once for each deprecated setting
    in use: `DJUST_WS_COMPRESSION`, `DJUST_VDOM_CACHE_*`,
    `DJUST_STATE_BACKEND`, `DJUST_REDIS_URL`, the `template_auto_call` /
    `virtual_keyed_ops` / `django_value_repr` keys, and a `TEMPLATES` entry
    naming `djust.template_backend.DjustTemplateBackend`. They keep working in
    1.x; 2.0 refuses to start while one is set.
