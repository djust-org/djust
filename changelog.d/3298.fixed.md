- **The `[HotReload]` startup banner no longer goes to stdout.** With `DEBUG=True` and `watchdog` installed, `enable_hot_reload()` runs on every management command and printed `[HotReload] Hot reload enabled for directories: ...` to stdout, so `manage.py djust_audit --dump-permissions > permissions.yaml` (and `--json`, `djust_ai_context --print`, `manage.py check`) began with that line and the file did not parse. The banner is now written to stderr, the failure case goes through `logger.error` only (it already reached stderr via logging's last-resort handler), and `logger.info` uses `%s` formatting. A subprocess test parses a redirected `djust_audit --dump-permissions` as YAML (#3298).
