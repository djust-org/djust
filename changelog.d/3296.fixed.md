- **`djust init` on a uv project no longer rewrites dependencies the project already declares.** It ran `uv add 'djust>=…' 'channels>=4.0' 'uvicorn[standard]>=0.30'` unconditionally, and `uv add` replaces an existing specifier, so `djust==1.2.2` became `djust>=1.2.2` and the `channels` and `uvicorn` bounds were dropped. It now reads `[project].dependencies` (matching by canonical package name, so extras, case and `-`/`_`/`.` spellings count) and runs `uv add` only for the missing packages; when none are missing it reports `packages unchanged` and goes straight to `manage.py check`. `--dry-run` prints the same trimmed command. A declared package that lacks an extra the scaffold needs (`uvicorn` without `[standard]`, the WebSocket library) still gets it: `uv add 'uvicorn[standard]'` with no specifier, which uv resolves by keeping the declared bounds, and an in-place edit of that `requirements.txt` line. A `pyproject.toml` that cannot be parsed keeps the old behaviour (#3296).
