- **The JIT attribute gate applies the column-type floor like the serialization path does.** `optimization/codegen.py::emittable_names`, the gate behind the compiled serializers and the Rust serializers, decided by attribute name only, so a column the type floor drops (a `BinaryField`, a type named in `LIVEVIEW_CONFIG['sensitive_field_types']`, an encrypted-named type) was read by a template that named it. The gate now asks `DjangoJSONEncoder._attr_is_readable`, the name rules followed by the type floor, which neither an allowlist nor an opt-out lifts. The gate's cache key carries the model class and the configured types, and a lazy-wrapped model is gated on the wrapped class's per-model sets rather than the wrapper's. 20 regression cases in `python/djust/tests/test_jit_gate_type_floor.py`.
