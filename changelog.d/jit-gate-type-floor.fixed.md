- **The JIT attribute gate applies the column-type floor like the serialization path does.** `optimization/codegen.py::emittable_names`, the gate behind the compiled serializers and the Rust serializers, decided by attribute name only, so a column the type floor drops (a `BinaryField`, a type named in `LIVEVIEW_CONFIG['sensitive_field_types']`, an encrypted-named type) was read by a template that named it. The gate now asks `DjangoJSONEncoder._attr_is_readable`, the name rules followed by the type floor, which neither an allowlist nor an opt-out lifts. The gate's cache key carries the model class and the configured types, and a full cache is cleared rather than frozen. The floor governs columns: a property, method, annotation or `values_list` row carrying the same value is outside it, as on the eager path. **Upgrade note:** a JIT page that displayed an encrypted-named (or configured-sensitive, or binary) column now renders it empty; to show such a value deliberately, precompute a plain value in `get_context_data()` or a property, or remove the type from `LIVEVIEW_CONFIG['sensitive_field_types']` / rename the field class. 22 regression cases in `python/djust/tests/test_jit_gate_type_floor.py`.
