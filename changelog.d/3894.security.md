- **The Python `data_table` template no longer trusts a marked-safe row value in an attribute (#3894).** A row URL (`row_url`, a link column), a link column's `link_class`, the row id of the selection checkbox and a column key are checked and escaped whatever the value is marked as (`mark_safe`, a lazy or `Markup` value); a marked-safe value in a TEXT cell still renders its markup.
