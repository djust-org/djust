- **The Python `data_table` template no longer trusts a marked-safe row value in an attribute (#3894).** A row URL (`row_url`, a link column), a link column's `link_class`, the row id of the selection checkbox, a column key and a column width are checked and escaped whatever the value is marked as (`mark_safe`, a lazy or `__html__` value), for any kind of column list; a marked-safe URL that was already HTML-escaped is now escaped once more (`&amp;` becomes `&amp;amp;`, so pass the plain URL). A marked-safe value in a TEXT cell still renders its markup.
