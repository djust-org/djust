- **Back now restores a legacy `enable_state_snapshot` view's state after a component event (#3237).** Back reads two sources, and the session save wins: `dispatch_mount` uses the signed token only when there is no save. The component route missed both. It saved to the session only for a `ComponentDeclaration`, so after any earlier view event Back restored that older save, and its frames carried no refreshed token, so without a save Back restored the mount-time state. A legacy opt-in view now saves on every component event, as the view route does on every event. The component route's full-HTML `html_update` and scoped `patch` frames also carry the refreshed `state_snapshot_signed` token, as the view route's frames do (#3098). A component `noop` changed nothing and carries none, as on the view route. New cases in `python/djust/tests/test_legacy_component_snapshot_3237.py`.
