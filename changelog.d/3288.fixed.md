- **`{% theme_select value=... %}` selects the matching option (#3288).** `value=` used to fall into the pass-through and render as an attribute on `<select>`, which browsers ignore, so an edit form always opened on the first option and saving it changed the field. The option whose `value` equals it (compared as strings) is now `selected`; an option dict's own `"selected"` still works, and the placeholder is selected only when no option is. Regression cases in `python/djust/tests/test_theming_component_attrs_3279_3288.py`.
