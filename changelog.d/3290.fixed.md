- **The `hidden` attribute hides themed components again (#3290).** `.progress-wrapper` and every other component class that sets `display: flex|grid|inline-*` overrode the user-agent `[hidden] { display: none }`, so toggling `hidden` on a progress bar did nothing. `components.css` now carries one `[hidden]:not([hidden="until-found"]) { display: none !important; }` guard.
