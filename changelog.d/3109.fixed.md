- **`PresenceMixin`'s examples list the mixin first, and the reversed order fails at class definition (#3109).**
  `python/djust/presence.py`'s three examples declared `class V(LiveView, PresenceMixin)`.
  Django's `View.__init__` does not call `super().__init__()`, so the mixin's
  `__init__` never ran and the first `track_presence()` raised
  `AttributeError: ... '_presence_tracked'` from inside `presence.py`. The
  examples (and the two ADRs that copied them) now read
  `class V(PresenceMixin, LiveView)`, and `PresenceMixin.__init_subclass__`
  raises a `TypeError` naming the class and the fix whenever a Django `View`
  precedes the mixin in the MRO. A class that listed the mixin after
  `LiveView` now fails when it is defined instead of on first use.
- **`MarkdownEditor`'s docstring lists the custom properties the CSS reads (#3109).**
  It listed `--dj-md-editor-min-height` (which sizes only the panes container)
  and omitted `--dj-md-editor-height`, the property that sizes the editing
  surface, and which is a fixed size rather than a minimum. The docstring and
  the Markdown editor guide now document both, plus the visual-mode
  properties; `test_markdown_editor_css_vars_3109` derives both sets from the
  stylesheets and fails if they drift.
