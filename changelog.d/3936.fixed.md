- With `LIVEVIEW_CONFIG["state_models_as_handles"]` on, a model held as LiveView state reads its relations through a filtered rebinding or a filtered loop operand on an explicit view: `{% with q=user|default:user %}{{ q.groups.count }}` and `{% for u in users|slice:":2" %}{{ u.groups.count }}` rendered empty, and now render what Django renders. Each state key holding a model, a model list or a QuerySet gets a floored handle bound for the render only (`RustLiveView.set_render_handles`, set on every sync); state, change detection, the state backend and the client payload keep the serialized dict. The flag is off by default. (#3936)
