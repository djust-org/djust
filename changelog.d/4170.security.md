- **The HTTP API and `@server_function` endpoints answer a `PermissionDenied` with the fixed message "Permission denied" (#4170).** The exception's text no longer reaches the caller on any view, under any policy, DEBUG included; it goes to the server log only, as on WebSocket and SSE. A test now pins every HTTP response body (`JsonResponse`, `HttpResponse*`, `StreamingHttpResponse`, the API error envelope) and client frame that interpolates an exception, package-wide, including a one-step flow through a local name; a new site fails until it is fixed or classified with its reason.
