- **`{% progress %}` draws under a strict CSP and exposes a progress value (#3969).** The fill was `style="width:N%"`, which a `style-src` without `'unsafe-inline'` refuses, so the bar rendered empty. The width is now a class, `dj-progress-w-0` to `dj-progress-w-100` (in `components.css`), on the Django tag, the native handler and `djust.components.Progress` (which rounds to a whole percent; `aria-valuenow` keeps the exact value). The native handler's track also gains `role="progressbar"`, `aria-valuenow` / `-min` / `-max` and an `aria-label`, as the Python tag's has (named by its `label=` when there is one; no renderer invents a name for an unlabelled bar). `djust.components.ui.Progress` (the Bootstrap / Tailwind one) is unchanged. Verified in a browser under `style-src 'self'`. Cases in `TestProgress` of `python/djust/tests/test_component_aria_v1_3_0_19.py`.
