- **A Python-bridged tag inside an overriding `{% block %}` rendered the parent for every call it made, whether or not it read `block.super` (#2918).** Output matched Django's, but side effects in the parent (a counter, a cache warmer, a bridged tag) ran several times as often: 60 handler calls against Django's 12 in the #2916 probe. The `block` a bridged tag receives is now a lazy object whose `super` renders the parent when it is read, and renders it again on every read (no memoization, as Django's `BlockNode.super()` is a method call), so the parent's tags run exactly as often as in Django's engine. It answers `context["block"].super()`, `block["super"]`, `block.get("super")` and `"super" in block` (the last never renders). 12 regression cases in `python/tests/test_block_super_bridge_lazy_2918.py`, one of them a 37-template matrix compared against Django's own engine on rendered output and per-tag call counts.
