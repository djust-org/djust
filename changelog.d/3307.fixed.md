- **Context processors ignored when `TEMPLATES` names the backend as `djust.template.backend.DjustTemplateBackend` (#3307).**
  `ContextMixin._get_context_processors` compared `BACKEND` against one literal spelling, so `request`, `user`, `perms`,
  `messages` and every project processor silently never reached the template under the canonical path. It, and the
  APP_DIRS template-dir collector, now match by class (`djust.utils.is_app_dirs_template_backend`): either dotted path,
  a project subclass, or the stock Django backend. 8 regression cases in
  `python/tests/test_template_backend_spelling_3307.py`.
