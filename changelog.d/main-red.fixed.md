- **The Django-to-Rust filter bridge no longer marks itself done when its first call finds no Django template engine.** A `TEMPLATES` holding only the djust backend left nothing to walk, yet the one-shot flag was set with nothing recorded, so a root LiveView's `{% load live_tags %}` filters (`field_value`, `has_errors`) failed with `Invalid filter` for the rest of the process. The bridge now stays armed until an engine exists. This was the order-dependent failure that turned `main` red on `python-tests (shard 1/4)`.
