- **Every class a theming component tag emits now has a rule in `components.css` (#3277).** `{% theme_select %}`, `{% theme_textarea %}`, `{% theme_radio %}`, `{% theme_nav_item %}`, `{% theme_mode_button %}`, the nav group, the preset selectors, the alert actions area and the input/select/textarea help and error text rendered as unstyled browser controls (a white `<select>` in dark mode). `.btn`, `.input` and every other rule that sets a width or height together with padding or a border now carries `box-sizing: border-box`, so a plain page no longer renders a 58px-tall text input. A test derives the emitted class list from the component templates and tag docstrings, so a new class or variant without a rule fails it.
