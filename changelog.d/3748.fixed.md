- **The Rust `Avatar` read a URL with a leading control character as having no scheme (#3748).** `url_scheme()` in `crates/djust_components/src/simple/avatar.rs` removed only tab, CR and LF before it looked for the scheme, so `"\x01blob:..."`, `"\x00file:..."` and `"\x1fintent:..."` failed the leading-letter test and reached `<img src>` as written, where `url_attr` returns `#`. It now strips leading C0 controls and space first, as Python's `urlsplit` and a browser do. The recorded gap (`KNOWN_RUST_MIRROR_GAPS`) in the sweep test is gone, the sweep corpus gained leading-control `blob:` / `file:` / `intent:` payloads, and `python/tests/test_avatar_rust_scheme_parity_3748.py` compares the Rust avatar with `url_attr` over every C0 control in every position and a seeded random sweep. The markdown renderer's three-scheme denylist is unchanged; the measurement is on the issue.
