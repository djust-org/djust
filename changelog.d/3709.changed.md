- **Test waits on Channels communicators take the 30 s default again; a ratchet keeps explicit short timeouts from regrowing (#3709).** An explicit `timeout=3` on `receive_json_from` / `receive_from` / `receive_output` / `connect` / `disconnect` overrides the 30 s default the root `conftest.py` installs (#3692), so the wait is a 3 s wall-clock bound again; a stop-the-world GC pause was measured at 3.38 s (#3708). 433 short awaited waits in 156 test files lost their `timeout=`: 404 plain waits, and 29 inside a `try` (26 `except: pass` drains, mostly of the connect frame, which always arrives; 2 `except: break` loops that read until a close or error frame the test then asserts; 1 benchmark fallback `except: response = {}`, which keeps its `try`). 34 helper definitions whose short `timeout=` default was forwarded to a wait (`_receive_until(..., timeout=3)` and its siblings) default to 30 s. `python/djust/tests/test_communicator_timeouts_ratchet_3709.py` counts, by AST, an awaited communicator wait with a short numeric timeout, a helper with a short forwarded default, and a call to such a helper with a short literal, per file against a baseline; it exempts only absence idioms (`receive_nothing`, the last line of a `pytest.raises` block, a `try` whose handlers only `pass` / `break` / `continue`). **It does not cover everything**: waits whose `timeout` is a variable (`remaining`, `deadline`), `asyncio.wait_for(..., <10)` and `asyncio.timeout(<10)` (not communicator waits), helpers imported from another module, and the exempt drains are counted in `UNCOVERED_BASELINE` (which also only falls) but not converted, so #3709 stays open for them. Of the 6 exempt drains, only two are absence windows (`test_ws_auth_close_socket.py`, which reads a `websocket.close`, and `test_sync_turn_wrapper_more_hops_3637.py`, which asserts no `mount` arrived); the other four (`test_live_auth_event_holders_and_user_checks.py`, `test_live_auth_outside_declarations.py`, `test_model_form_route_change_3125.py`, `test_mount_object_permission_after_params.py`) read until a frame that does arrive in the positive case, fail 68 tests when every outgoing frame is delayed 3.5 s, and are kept only because converting them means restructuring the loop. The baseline holds one entry on purpose: `python/djust/tests/test_ws_communicator_defaults_3464.py` pins that an explicit timeout still wins over the default, so it passes `timeout=0.01`.
