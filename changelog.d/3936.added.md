- Opt-in `LIVEVIEW_CONFIG["state_models_as_handles"]` (default off; the default path is unchanged): with it on, a model held as LiveView state reads its relations through a filtered rebinding on an explicit view: `{% with q=user|default:user %}{{ q.groups.count }}` renders empty with the flag off and what Django renders with it on (a filtered loop operand over a QuerySet or model list renders on the default path too, #4069). Each state key holding a model, a model list or a QuerySet gets a floored handle bound for the render only (`RustLiveView.set_render_handles`, set on every sync); state, change detection, the state backend and the client payload keep the serialized dict. The flag is off by default in 2.0; turning it on by default is an open maintainer decision (ADR-027 addendum, note of 2026-11-21). (#3936)
