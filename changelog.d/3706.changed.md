- **`LiveViewTestClient.mount()` now runs `handle_params()` (#3706).** The client used to call `mount()` only, so state a view builds in `handle_params()` was missing under test while the HTTP GET and the socket mount always had it. A test of a view whose `handle_params()` assumes a key the URL does not carry, or raises, now fails the way the page does; the same applies to `assert_http_ws_djid_parity()` and `create_test_view()`, which mount through the same code. Two snippets in the navigation guide called helpers they never defined from `handle_params()` (`fetch_products`, `_load_tab_data`); the doc-snippet harness had never run those hooks, found them once the client did, and the snippets now define them.
