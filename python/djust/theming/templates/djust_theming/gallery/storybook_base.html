{% comment %} The mount root wraps the SIDEBAR as well as the content — that is the whole point of it. The sidebar's search box and category headers are `dj-input` / `dj-click` server events, and djust only binds and dispatches events for elements inside the dj-root region. With the root around the content only, the sidebar's controls rendered correctly, carried the right attributes, and sent nothing: no `dj-id` was ever stamped on them and a click produced no frame at all. Wrapping outside `.sb-layout` is layout-neutral: `.sb-sidebar` is `position: fixed` and so out of flow, and `.sb-content`'s `flex: 1` still resolves against `.sb-layout`. {% endcomment %}
