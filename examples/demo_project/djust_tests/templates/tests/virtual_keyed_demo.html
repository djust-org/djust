dj-virtual — keyed splice ops (#2017 / ADR-026)

The keyed ops work; the flag is still OFF for a different reason. This banner used to say an insert at position 5 lands at the TAIL with the flag on or off — that was issue #2164's withdrawn second diagnosis, and it is false. PR #2167 showed the differ and the applier were both correct and the flag simply never reached Rust. Re-measured 2026-08-11 with the flag ON: an insert at 5 lands at pool index 5, a remove drops the right key, and a reverse is exact.

What keeps the default OFF is #2185: [dj-virtual] initialisation is intermittently lost on page load, and on such a load a VirtualInsert hits an uninitialised container and forces a full HTML recovery. If the list below shows all 60 rows instead of a ~13-row window, you are on an affected load — that is #2185, not the keyed ops.
