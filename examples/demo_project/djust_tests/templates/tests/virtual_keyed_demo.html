dj-virtual — keyed splice ops (#2017 / ADR-026)

Keyed splice ops are ON by default since 1.1.0 (ADR-026 iteration 3). Use the buttons and watch the pool ORDER, not its size.

With the flag OFF, an insert at position 5 lands at the TAIL, a removal does not land at all, and a reverse is ignored — the append-only absorb heuristic cannot express mid-list structure. With it ON, the insert lands at index 5, the removal drops the right key, and the reverse is exact.

That A/B only became measurable once #2185 and #2194 were fixed: before them the list was intermittently never initialised, so both arms were really the OFF arm — which is how this feature accumulated four withdrawn diagnoses. Opt out with LIVEVIEW_CONFIG['virtual_keyed_ops'] = False.
