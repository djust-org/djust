# Component tags in use

A names-only list of the template tags that the project's own apps use, from a
static scan of the project's own apps on 2026-10-28. It exists to prioritise
work on the component catalogue. It does **not** decide what stays in djust:
every component tag stays in core (#4002), and a tag missing from this list is
not a candidate for removal on that ground. The scan cannot see private
deployments by other users.

"Apps" is how many of the scanned apps use the tag at least once.
