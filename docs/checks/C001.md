### C001 — ASGI_APPLICATION not set
- **Severity**: Error
- **Method**: Runtime (settings inspection)
- **What it detects**: `settings.ASGI_APPLICATION` is missing or None
- **Suppression**: `SILENCED_SYSTEM_CHECKS = ["djust.C001"]`
- **False positives**: None known; required for WebSocket support

<!-- doc: guide -->
### C001: ASGI_APPLICATION not set

**Severity**: Error

**What causes it**: Your Django settings file is missing the `ASGI_APPLICATION` setting. djust requires ASGI for WebSocket support.

**What you see**: LiveView pages load as static HTML. No WebSocket connection is established.

**Fix**:

```python
# settings.py
ASGI_APPLICATION = "myproject.asgi.application"
```
