### V020 — Retired
- **Retired in**: 2.0 (the actor system was removed)
- **What it did**: reported a `use_actors = True` view that declared an interactive component from `djust.components.interactive`
- **Why it was retired**: `use_actors` no longer exists. A view that still sets it is refused with `ImproperlyConfigured`, when the class is created and again on the mount path
- **Migration**: remove `"V020"` from `suppress_checks`, `SILENCED_SYSTEM_CHECKS` and `# noqa` comments at your convenience; they now have no effect. The ID is never reused
