### T010 — dj-click used for navigation
- **Severity**: Warning
- **Method**: Template scan (regex over each tag: `dj-click` plus a navigation-style attribute)
- **What it detects**: an element with `dj-click` and a navigation-style attribute (`data-view`, `data-tab`, `data-page`, `data-section`, or the same names as `dj-value-*`); prefer `dj-patch` for URL state updates. Names are matched whole, so `data-viewport` and `dj-value-viewer` do not count
- **Suppression**: `SILENCED_SYSTEM_CHECKS = ["djust.T010"]`
- **False positives**: In-view tab or page state that is not URL state, such as djust's own Tabs component (`dj-click="activate_tab" dj-value-tab=...`); suppress it for those templates

### T010: dj-click used for navigation

**Severity**: Warning

**What causes it**: A template element uses `dj-click` together with navigation-related data attributes (`data-view`, `data-tab`, `data-page`, or `data-section`, or the `dj-value-*` form of each such as `dj-value-tab`). This pattern suggests you're implementing navigation, which should use `dj-patch` instead for proper URL updates and browser history support.

**What you see**: Navigation works but the browser URL doesn't update, and the back button doesn't work as expected. Users cannot bookmark or share specific views.

**Fix**:

<!-- doc-snippet-check: anti-pattern -->
```html
<!-- WRONG -- dj-click for navigation -->
<button dj-click="show_settings" data-view="settings">Settings</button>

<!-- WRONG -- the same navigation sent as an event param -->
<button dj-click="show" dj-value-tab="settings">Settings</button>

<!-- CORRECT -- use dj-patch for navigation -->
<a href="?view=settings" dj-patch>Settings</a>
```

A bare `dj-patch` on an `<a>` patches to its `href`. (A non-empty `dj-patch` value is itself the target URL.)

In your LiveView, read the URL parameter in the `handle_params()` lifecycle hook. It is not an event handler, so don't decorate it with `@event_handler`:

```python
class MyView(LiveView):
    current_view = state("dashboard")

    def handle_params(self, params, uri):
        # Called after mount and on every dj-patch / back-forward URL change
        self.current_view = params.get("view", "dashboard")
```
