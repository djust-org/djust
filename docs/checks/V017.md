### V017 — Retired
- **Retired in**: 2.0 (the actor system was removed)
- **What it did**: reported a strict-policy `async def` event handler on a `use_actors = True` view, which actor dispatch rejected before the handler ran
- **Why it was retired**: `use_actors` no longer exists. A view that still sets it is refused with `ImproperlyConfigured`, when the class is created and again on the mount path
- **Migration**: remove `"V017"` from `suppress_checks`, `SILENCED_SYSTEM_CHECKS` and `# noqa` comments at your convenience; they now have no effect. The ID is never reused
